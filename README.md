# alaio-web-lab

Рабочая лаборатория веб-дизайна Alaio: реальные секции SaaS-лендингов.

## Дизайн-система

[Все правила дизайна Alaio](docs/design-system.md) — точка входа в три раздела:

- [Основы](docs/foundations/README.md) — визуальный стиль, цвета, шрифты для веба и мобильных экранов, иконки, отступы, Auto Layout, скругления и ссылки на Figma.
- [Компоненты](docs/components/README.md) — переиспользуемые элементы (кнопки, чип, вкладки меню, пункт FAQ, заголовочная группа).
- [Блоки](docs/blocks/README.md) — готовые секции страницы.

Нерешённые вопросы и противоречия — в [docs/design-system-open-questions.md](docs/design-system-open-questions.md).
