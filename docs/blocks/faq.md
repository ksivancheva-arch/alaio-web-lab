# FAQ

Композиция всей секции. Правила отдельного вопроса — см. [Пункт FAQ (компонент)](../components/faq-item.md).

## 1. Назначение

Заголовок секции и вертикальный список раскрывающихся вопросов.

## 2. Источник и статус спецификации

Источник: [Untitled, node 32:692](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=32-692). Статус: полная спецификация композиции.

## 3. Структура

- Заголовок FAQ.
- Вертикальный список раскрывающихся пунктов — см. [Пункт FAQ](../components/faq-item.md) для структуры пункта.

## 4. Геометрия

- Ширина эталонного макета: **1320 px** (см. [Сетка, контейнеры и отступы](../foundations/layout-grid.md)).
- Высота: по содержимому (`hug`). Высота текущего примера — **612 px** — измерение примера, не фиксировать для другого контента.
- Внутренние отступы контейнера: **0 px**.
- Скругление внешнего контейнера: **0 px** — параметр этого блока: в отличие от карточек-секций (30 px), у FAQ-контейнера скругления нет вообще, это не одна из типовых карточек-секций и не ошибка.
- Расстояние между заголовком и списком: **40 px** (совпадает с `spacing/content`).
- Список занимает всю ширину контейнера. Расстояние между пунктами: **10 px**.

## 5. Типографика

Заголовок FAQ: Google Sans Flex, **500 / Medium**, **40 px**, line-height **120% / 48 px**, letter-spacing **0**, цвет `#251E49` (`text/primary`). Соответствует стилю **H2** (см. [Типографика](../foundations/typography.md)).

## 6. Цвета и варианты

Фон: **`#FFFFFF`** (`bg/primary`). Обводка отсутствует.

## 7. Состояния и поведение

Состояния отдельного пункта (открыт/закрыт, кнопка раскрытия) — см. [Пункт FAQ](../components/faq-item.md).

## 8. Адаптивность

Отдельные мобильные значения не заданы.

## 9. Правила контента

Выравнивание заголовка — **по центру**, высота по содержимому. Общее правило контейнера секции уже центрирует каждую секцию по горизонтали на странице (см. [Сетка, контейнеры и отступы](../foundations/layout-grid.md)); центрирование именно текста заголовка здесь — часть спецификации этого блока, а не единственное в системе исключение.

В источнике показаны шесть вопросов:

1. How do I reach Bitrix24 customer support?
2. Is my data secure in Bitrix24?
3. How to upgrade my storage space?
4. How do I migrate data to Bitrix24?
5. How do I hide the Bitrix24 tools I don't need?
6. What is an HRMS?

Первый пункт показан раскрытым, остальные — закрытыми. Это состав конкретного примера, а не обязательное количество пунктов для всех FAQ. Использовать только вопросы и ответы из утверждённого источника. **Не придумывать ответы для закрытых пунктов** — в выбранном макете их текстов нет.

## 10. Связанные компоненты и токены

| Значение спецификации | Токен Alaio | Совпадает? |
|---|---|---|
| `#FFFFFF` (фон контейнера) | `bg/primary` | Да |
| `#251E49` (текст заголовка) | `text/primary` | Да |
| 40 px (заголовок → список) | `spacing/content` | Да |
| 0 px (радиус контейнера), 10 px (между пунктами) | — | Новые значения, токенов под них пока нет |

Связанный компонент: [Пункт FAQ](../components/faq-item.md).

## 11. Проверка

- Ширина эталонного блока — **1320 px**.
- Между заголовком и списком — **40 px**. Между пунктами — **10 px**.
- Заголовок — H2, по центру, `#251E49`.
- Высота списка и раскрытых пунктов зависит от контента.
- Проверка отдельного пункта — см. [Пункт FAQ → Проверка](../components/faq-item.md#11-проверка).
