# Hero

## 1. Назначение

Первый экран страницы: заголовок, подзаголовок, декоративная фоновая анимация.

## 2. Источник и статус спецификации

Правила зафиксированы по конкретной кодовой реализации (HTML/CSS/JS), а не по Figma-макету. Отдельного узла Figma не зафиксировано. Статус — частичная спецификация.

## 3. Структура

Заголовок, подзаголовок, фоновая canvas-анимация под контентом.

## 4. Геометрия

- Подзаголовок — ширина **853 px**.
- Ширина/геометрия заголовка, контейнера и отступ между заголовком и подзаголовком отдельно источником не подтверждены; по общему правилу (см. [Заголовочная группа](../components/heading-group.md)) должно быть 10 px, но отдельного измерения для Hero нет.
- Остальная геометрия — Не задано.

## 5. Типографика

- Заголовок — Google Sans Flex 600 / 54 px — соответствует **H1 Accent** (см. [Типографика](../foundations/typography.md)).
- Подзаголовок — Inter 500 / 18 px, `opacity: .8`. Отличие от общего правила подзаголовков (Regular 400, см. [Заголовочная группа](../components/heading-group.md)) — тот же паттерн «Medium + opacity .8» повторяется и в [Слайдере с буллетами](bullet-slider.md), общее правило по умолчанию не меняется.

## 6. Цвета и варианты

Не задано (кроме непрозрачности подзаголовка, см. раздел 5).

## 7. Состояния и поведение

Фоновая canvas-анимация: `position: absolute`, под контентом (`z-index: 0; pointer-events: none`); контент — `z-index: 1`. Тип и поведение самой анимации — Не задано.

## 8. Адаптивность

Не задано.

## 9. Правила контента

Ширина подзаголовка (853 px) ограничивает длину строки — сознательное решение макета.

## 10. Связанные компоненты и токены

[Заголовочная группа](../components/heading-group.md) — частично (нет подтверждённого gap и CTA для Hero).

## 11. Проверка

- Заголовок — Google Sans Flex 600/54.
- Подзаголовок — Inter 500/18, ширина 853, opacity .8.
- Фон — canvas-анимация, z-index 0 под контентом (z-index 1).
- Остальные параметры — не проверять по этой странице, они не заданы источником.
