# Customer Stories Slider

Слой в Figma назывался «Слайдер отзывы» — переименован в `Customer Stories Slider` (17 сентября 2026), чтобы соответствовать соглашению об английских именах блоков (см. [CLAUDE.md](../../CLAUDE.md)).

## 1. Назначение

Секция отзывов/кейсов клиентов: заголовок + ряд наград/бейджей платформ отзывов → горизонтальный ряд карточек-кейсов → стрелка прокрутки → CTA.

## 2. Источник и статус спецификации

Источник: [Untitled, node 124:3286](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=124-3286). Статус: полная спецификация одного состояния (со скрытой левой стрелкой — то есть показан «первый» экран прокрутки).

## 3. Структура

Вертикальный стек (gap **40 px**): заголовочная строка (заголовок слева + бейджи наград справа) → блок карточек (ряд из 4 карточек-кейсов + стрелка прокрутки) → ряд CTA (Primary CTA + Tertiary/Icon).

## 4. Геометрия

- Контейнер: паддинг **60 px** сверху/снизу. Радиус **не задан** (в отличие от большинства других карточек-секций) — контейнер занимает всю ширину без скругления.
- Заголовочная строка: ширина **1320 px**, `justify-content: space-between`; заголовок — **540 px**; ряд бейджей — **634 px**, выровнен по правому краю, перенос разрешён (`flex-wrap`), бейджи — **~126×97 px** каждый, без явного gap (встык).
- Ряд карточек: 4 карточки по **410 px**, gap **20 px**, высота по содержимому (**445 px** в примере).
- Карточка: фон белый, радиус **20 px** — совпадает со ступенью «крупный блок/превью» из [общей таблицы радиусов](../foundations/radii-strokes.md); тень **`Sh1`** (см. [Card Frame](card-frame.md#4-геометрия) для описания стиля) — соответствует правилу «тень, если у блока есть свой фон» ([Карточка-преимущество](../components/feature-card.md)), так как контейнер этого блока залит `Soft Cloud`; паддинг **20 px**, вертикальный gap **12 px**.
  - Строка лого+название: `justify-content: space-between`, лого-плашка **116×58 px** (без рамки/фона — просто область под растровый логотип), название компании — текст справа.
  - Изображение кейса: **370×181 px**, радиус **10 px**, `object-cover`.
  - Заголовок кейса: ширина **370 px**, высота по содержимому (в примере **85–96 px**).
  - Кнопка-стрелка (`Buttons / Small`): **34×34 px** (24×24 глиф + паддинг 5 px), обводка **2 px** `Friendly Purple`, радиус **8 px**, без заливки, прижата к правому нижнему углу карточки.
- Стрелка прокрутки (правая, видимая): круг **46×46 px**, радиус **100 px** (полный круг), паддинг **5 px**, глиф-шеврон **38×38 px**. Левая стрелка (`hidden="true"` в источнике) — того же размера, скрыта в этом состоянии (вероятно, появляется не на первом экране прокрутки).
- CTA-ряд: gap **20 px** между Primary CTA (**192×54 px**, паддинг 36/16, радиус 12) и Tertiary/Icon (паддинг 36/16, без фона, иконка **28×28 px** после текста).

## 5. Типографика

- Заголовок — **H2** (Google Sans Flex Medium 500, 44 px, 120%), цвет `text/primary`, слева (не по центру).
- Название компании (в карточке): Inter Regular, 16 px (**Body Small**).
- Заголовок кейса: Inter Medium 500, 22 px, 120% — стиль **H5** (см. [Типографика](../foundations/typography.md)), непрозрачность 100%.
- CTA и Tertiary/Icon: font `Montserrat:Bold` в источнике — расходится с общим стилем **Button** (Google Sans Flex Semibold, см. [Типографика](../foundations/typography.md)); то же расхождение уже встречалось и было решено в блоке [Partners](partners.md) в пользу стиля Button — здесь применяется то же решение, Montserrat не переносить как правило.

## 6. Цвета и варианты

- Фон контейнера — `Soft Cloud` (`#F4F4F4`).
- Карточка — белая заливка, без обводки, тень `Sh1`.
- Кнопка-стрелка в карточке: обводка `Friendly Purple` (`#A677FC`), без заливки, глиф фиолетовый.
- Стрелка прокрутки (нижний слой, круглая): заливка `rgba(37,30,73,.6)` (полупрозрачный тёмный, близко к Midnight Ink), обводка `rgba(37,30,73,.2)`, тень `0 10px 20px rgba(0,0,0,.25)` — новые значения, не входящие в палитру токенов, отдельная (третья) тень в системе помимо `Sh1`.
- Четвёртая (последняя видимая) карточка показана с непрозрачностью контейнера **80%** — тот же приём «затухания», что и в [Card Frame Scroll](card-frame-scroll.md), сигнализирует прокручиваемость ряда.
- CTA — фон `Honey Yellow` (`#FFD972`), текст `text/primary`.

## 7. Состояния и поведение

- Ряд карточек прокручивается горизонтально; левая стрелка скрыта в начальном состоянии, правая видима — типичный паттерн «стрелка назад появляется после первого шага прокрутки». Второе состояние (с прокруткой) в источнике не зафиксировано.
- Четвёртая карточка с пониженной непрозрачностью — визуальный намёк на дополнительный контент за краем экрана, не финальное состояние контента.

## 8. Адаптивность

Не задано.

## 9. Правила контента

- Заголовок, 4 кейса (компания, изображение, заголовок), бейджи наград и тексты CTA — содержимое конкретного примера, не обязательный состав блока.
- Количество карточек (4) и наград (5) — свойства примера, не ограничение блока.

## 10. Связанные компоненты и токены

- [Кнопки](../components/buttons.md) — CTA (Primary), плюс два варианта, ранее не задокументированных: **`Buttons / Small`** (круглая кнопка-стрелка, обводка, без заливки — здесь и как круглая стрелка прокрутки с другой заливкой) и **`Buttons / Tertiary / Icon`** (текст + иконка, без фона).
- Тень `Sh1` — см. [Карточка-преимущество](../components/feature-card.md) и [Card Frame](card-frame.md).
- Радиус 20 px (карточка) — ступень «крупный блок/превью», [Радиусы и обводки](../foundations/radii-strokes.md).
- `Soft Cloud` (`#F4F4F4`), `Friendly Purple` (`#A677FC`), `Honey Yellow` (`#FFD972`), `text/primary` (`#251E49`) — [Цвета и градиенты](../foundations/colors.md).
- Стиль **H5** — см. [Типографика](../foundations/typography.md) (также используется в [Пункте FAQ](../components/faq-item.md)).

## 11. Проверка

- Контейнер: паддинг 60/60, фон `#F4F4F4`, без радиуса.
- Заголовочная строка: 1320 px, space-between; заголовок 540 px; бейджи 634 px справа.
- Ряд карточек: 4×410 px, gap 20; карточка — радиус 20, тень `Sh1`, паддинг 20, gap 12.
- Изображение кейса 370×181 радиус 10; заголовок кейса — H5 22px/120%; кнопка-стрелка 34×34 обводка `#A677FC`.
- Стрелка прокрутки: круг 46×46, `rgba(37,30,73,.6)` + тень `0 10px 20px rgba(0,0,0,.25)`.
- 4-я карточка — непрозрачность контейнера 80%.
- CTA: Primary 192×54 `#FFD972`; Tertiary/Icon — текст+иконка 28×28, без фона.
