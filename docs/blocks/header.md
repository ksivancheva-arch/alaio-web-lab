# Хедер — поведение при прокрутке и наведении

Актуальная геометрия, цвета и состав хедера — в [Хедере (Figma)](header-figma.md) (решение от 15 сентября 2026: между двумя источниками расхождения устранены в пользу Figma-версии, кодовые значения ниже больше не считать самостоятельным источником геометрии/цвета). Эта страница фиксирует только то, что статичный Figma-макет не может показать: закрепление при прокрутке и hover-состояния.

## 1. Назначение

Поведение хедера при прокрутке и наведении — дополняет [Хедер (Figma)](header-figma.md), не дублирует его геометрию.

## 2. Источник и статус спецификации

Правила зафиксированы по конкретной кодовой реализации (HTML/CSS/JS), а не по Figma-макету. Статус: только поведенческие факты (раздел 7); геометрия и цвета этой кодовой версии (высота 88 px, тень `0 2px 3px rgba(0,0,0,.09)`, радиус пункта меню 10 px без учёта пилюль) заменены версией из [Хедера (Figma)](header-figma.md) и здесь не приводятся.

## 7. Состояния и поведение

- Хедер остаётся закреплённым сверху при прокрутке (`position: sticky; top: 0; z-index: 5`).
- Пункт меню — hover-фон `#F4F4F4`.
- CTA — hover меняет заливку `#FFD972` → `#FFC800`.
