# Top Menu Slider

## 1. Назначение

Карточка-секция с горизонтальными вкладками, переключающими превью продукта.

## 2. Источник и статус спецификации

Источник: [alaio-sites, node 190:41107](https://www.figma.com/design/mI7upMBDx8OpZ35XX4Pld9/alaio-sites?node-id=190-41107). Статус: полная спецификация.

## 3. Структура

Карточка → колонка контента (заголовочная группа → вкладки верхнего меню → превью продукта → CTA).

## 4. Геометрия

- Контейнер: фон задаётся пользователем (не фиксированный токен), радиус **30 px**.
- Внутренний паддинг: **60 px** сверху и снизу, по бокам — 0 (центрирование достигается фиксированной шириной колонки контента).
- Колонка контента — фиксированная **1100 px**, центрирована в карточке.
- Вертикальный ритм внутри колонки — единый gap **40 px** между: заголовочный блок → вкладки → превью продукта → CTA (тот же токен, что и `spacing/content` / `spacing/action`).
- Область превью продукта: инстанс мокапа (например `CRM`) — **880×430**, радиус **20 px** (ступень «крупный блок» из [Радиусов и обводок](../foundations/radii-strokes.md)), центрирован в колонке 1100 px (по 110 px с каждой стороны).

## 5. Типографика

Заголовок — **H1 Accent** (Google Sans Flex SemiBold 50 px), подзаголовок — **Body Regular**. См. [Заголовочная группа](../components/heading-group.md).

## 6. Цвета и варианты

Цветовой вариант вкладок (лавандовый / серый фон) зависит от фона карточки — полные таблицы см. [Вкладки меню → Цвета и варианты](../components/menu-tabs.md#6-цвета-и-варианты).

CTA — фон `accent/yellow` (`#FFD972`), см. [Кнопки](../components/buttons.md).

## 7. Состояния и поведение

Переключение активной вкладки меняет превью продукта. Геометрия и типографика вкладок — см. [Вкладки меню](../components/menu-tabs.md).

## 8. Адаптивность

Не задано.

## 9. Правила контента

Не задано (конкретные тексты заголовка/подзаголовка и число вкладок — по макету).

## 10. Связанные компоненты и токены

- [Заголовочная группа](../components/heading-group.md), [Вкладки меню](../components/menu-tabs.md) (вариант «верхнее меню»), [Кнопки](../components/buttons.md) (Primary CTA, 183×54, паддинг 36/16, радиус 12).
- Радиус 30 px (карточка), 20 px (превью) — [Радиусы и обводки](../foundations/radii-strokes.md).

## 11. Проверка

- Карточка: радиус 30, паддинг 60/0.
- Колонка контента: 1100 px, gap 40 между всеми элементами.
- Превью: 880×430, радиус 20, отступы по 110 px с каждой стороны колонки.
- CTA: 183×54, радиус 12, `#FFD972`, паддинг 36/16.
