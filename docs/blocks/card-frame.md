# Card Frame

Пример в источнике во всех вариантах — «AI security is a shared responsibility». Это название и текст конкретного примера, не блока. Три варианта, найденные в источнике под родственными именами Figma-слоёв (`Card frame`, `Card frame and image`, и инстанс `Card frame` внутри [Bullet Slider](bullet-slider.md)) — один блок с разным фоном/иллюстрацией, а не три разных блока.

## 1. Назначение

Карточка-секция: заголовок + текст → иллюстрация → ряд из нескольких карточек-преимуществ (вариант «по центру» компонента [Карточка-преимущество](../components/feature-card.md)).

## 2. Источник и статус спецификации

- **Тёмный** — [Untitled, node 85:1472 «Card frame»](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=85-1472).
- **Светлый с картинкой** — [Untitled, node 96:2795 «Card frame and image»](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=96-2795).
- **Светлый с обводкой** — вложенный инстанс `Card frame` (node 105:5171) внутри инстанса [Bullet Slider](bullet-slider.md) (node 105:5338) — то есть этот вариант встроен как завершающая секция внутри блока Bullet Slider, а не используется отдельно.

Статус: полная спецификация для всех трёх вариантов. Тёмный вариант первым подтвердил геометрию иконки/заголовка для варианта «по центру» компонента [Карточка-преимущество](../components/feature-card.md) — до этого она была не задана.

## 3. Структура

Вертикальный стек (общий для всех вариантов): иллюстрация + заголовочная группа (сгруппированы) → ряд карточек-преимуществ (вариант «по центру»).

## 4. Геометрия

**Общее для всех вариантов**

- Заголовочная группа: ширина 1100 px, gap 10 px между заголовком и подзаголовком (стандарт), по центру.
- Ряд карточек: gap 10 px, высота 225 px, 3 карточки, каждая `flex: 1 0 0` (Fill — режим «3 карточки» из [Карточки-преимущества](../components/feature-card.md)).
- Карточка: паддинг 20 px, вертикальный gap 10 px, радиус 10 px.
- Иконка-плашка: 36×36 px, паддинг 8 px, радиус 8 px, глиф 24×24 px, по центру.

**Различия между вариантами**

| | Тёмный | Светлый с картинкой | Светлый с обводкой |
|---|---|---|---|
| Радиус контейнера | **40 px** (новая ступень, см. [Радиусы и обводки](../foundations/radii-strokes.md)) | **30 px** (карточка-секция) | **30 px** |
| Паддинг контейнера | 20 px сверху / 60 px снизу | 20 px сверху / 60 px снизу | 40 px сверху/снизу (`py-40`) |
| Обводка контейнера | Нет | Нет | 1 px, `vibecode/200` (`#DDD8FC`) |
| Иллюстрация | 1100×232 px, радиус 10 px, декоративные круги + плашка ChatGPT-логотипа на градиентном фоне | 1100×232 px, радиус 10 px, скруглённый круглый глифовый значок (бренд-градиент + маскированные круги + плашка ChatGPT-логотипа) с фоновым паттерном «бинарный код» и растушёвкой к цвету фона по всем четырём краям | 1100×247 px (не 232 — другое измерение того же слота, см. [Bullet Slider](bullet-slider.md)), простое растровое изображение без декоративной растушёвки |
| Карточка: заливка/обводка | Обводка 1 px `Friendly Purple` (`#A677FC`), без заливки | Заливка `Pure White`, обводка 0.5 px `Soft Cloud` (`#F4F4F4`), + тень `Sh1` (см. ниже) | Заливка `Pure White`, обводка 0.5 px `Soft Cloud`, + тень `Sh1` |

Правило компонента «заливка или обводка, не обе одновременно» ([Карточка-преимущество](../components/feature-card.md)) выполняется буквально в тёмном варианте; в светлых вариантах карточка использует **и** заливку, **и** тонкую (0.5 px) обводку — см. [открытые вопросы](../design-system-open-questions.md).

⚠ **Тень `Sh1`.** Оба светлых варианта используют именованный стиль тени `Sh1` — пять наложенных `drop-shadow` (мягкая многослойная тень, ключевые слои: `0 4px 34px rgba(118,118,118,.08)`, `0 4px 16px rgba(118,118,118,.10)`, `0 2px 5px rgba(118,118,118,.05)`, плюс два тонких контурных слоя). Это противоречит правилу «без теней» в [Карточке-преимуществе](../components/feature-card.md) — см. [открытые вопросы](../design-system-open-questions.md).

## 5. Типографика

- Заголовок — **H2** (Google Sans Flex Medium 500, 44 px, 120%), по центру.
- Подзаголовок — **Body Regular** (Inter Regular, 18 px, 140%), непрозрачность 90% (см. [Типографика](../foundations/typography.md)).
- Заголовок карточки — **Body Semibold** (Inter Semi Bold, 18 px), по центру.
- Текст карточки — **Body Small** (Inter Regular, 16 px), непрозрачность 90%, по центру.

Совпадает во всех трёх вариантах — различается только цвет (см. раздел 6).

## 6. Цвета и варианты

| | Тёмный | Светлый с картинкой | Светлый с обводкой |
|---|---|---|---|
| Фон контейнера | `Midnight Ink` (`#251E49`) | `Soft Cloud` (`#F4F4F4`) | Нет заливки (виден фон страницы/родителя) |
| Цвет текста (заголовок, подзаголовок, текст карточек) | Белый (`Pure White`) | `text/primary` (`#251E49`) | `text/primary` (`#251E49`) |
| Фон иконки-плашки | `Friendly Purple` (`#A677FC`, `accent/brand`) | `Friendly Purple` (`#A677FC`) | `Friendly Purple` (`#A677FC`) |
| Глиф иконки | Белый | Белый | Белый |
| Заливка/обводка карточки | Обводка `Friendly Purple` | Заливка белая + обводка `Soft Cloud` | Заливка белая + обводка `Soft Cloud` |

Тёмный вариант — как в [Metaball Sidebar Slider](metaball-slider.md): первый пример тёмной темы, здесь — второй такой блок в системе.

## 9. Правила контента

- Текст заголовка, подзаголовка и трёх карточек — содержимое конкретного примера («Secure cloud infrastructure», «Data encryption», «Identity and access controls»), одинаковое во всех трёх вариантах, не обязательный состав блока.
- Число карточек (3, Fill) — один из двух режимов компонента [Карточка-преимущество](../components/feature-card.md); шесть карточек (Fixed) в этом блоке не встречены (но встречены в [Card Frame Scroll](card-frame-scroll.md)).

## 10. Связанные компоненты и токены

- [Карточка-преимущество](../components/feature-card.md) (вариант «по центру», 3 карточки).
- [Заголовочная группа](../components/heading-group.md).
- [Bullet Slider](bullet-slider.md) — встраивает светлый вариант с обводкой как свою завершающую секцию.
- Midnight Ink (`#251E49`), Friendly Purple (`#A677FC` / `accent/brand`), Soft Cloud (`#F4F4F4`), `vibecode/200` (`#DDD8FC`) — [Цвета и градиенты](../foundations/colors.md).
- Радиус 40 px (тёмный контейнер, новое значение), 30 px (светлые контейнеры), 10 px (карточка, иллюстрация), 8 px (иконка-плашка) — [Радиусы и обводки](../foundations/radii-strokes.md).

## 11. Проверка

- Общее: заголовочная группа 1100 px по центру, ряд карточек gap 10 высота 225 (3×Fill), карточка паддинг 20 gap 10 радиус 10, иконка-плашка 36×36 радиус 8 паддинг 8, глиф 24×24, фон `#A677FC`, белый глиф.
- Тёмный: контейнер радиус 40, паддинг 20/60, фон `#251E49`, обводка карточки 1px `#A677FC` без заливки, весь текст белый.
- Светлый с картинкой: контейнер радиус 30, фон `#F4F4F4`, паддинг 20/60, карточки — белая заливка + обводка 0.5px `#F4F4F4` + тень `Sh1`, текст `text/primary`.
- Светлый с обводкой: контейнер радиус 30, паддинг 40/40, обводка 1px `#DDD8FC`, без заливки; карточки — как в варианте «с картинкой»; иллюстрация 1100×247 (не 232).
