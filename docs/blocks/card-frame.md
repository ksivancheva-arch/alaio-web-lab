# Card Frame

Пример в источнике — «AI security is a shared responsibility». Это название и текст конкретного примера, не блока.

## 1. Назначение

Тёмная карточка-секция: заголовок + текст → крупная иллюстрация → ряд из нескольких карточек-преимуществ (вариант «по центру» компонента [Карточка-преимущество](../components/feature-card.md)).

## 2. Источник и статус спецификации

Источник: [Untitled, node 85:1472 «Card frame»](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=85-1472). Статус: полная спецификация для одного разобранного примера (3 карточки). Это первый реальный экземпляр варианта «по центру» компонента [Карточка-преимущество](../components/feature-card.md) — уточняет геометрию иконки/заголовка, которая ранее была не задана для этого варианта.

## 3. Структура

Вертикальный стек: иллюстрация + заголовок/текст (сгруппированы) → ряд карточек-преимуществ (вариант «по центру»).

## 4. Геометрия

- Контейнер: радиус **40 px** — новая ступень радиуса, не входящая в [общую таблицу](../foundations/radii-strokes.md) (ближайшая — 30 px для карточки-секции). Паддинг **20 px сверху / 60 px снизу**, gap **40 px** между иллюстрацией+заголовком и рядом карточек.
- Иллюстрация: **1100×232 px**, радиус **10 px** — та же геометрия слота, что и в [Bullet Slider](bullet-slider.md).
- Заголовочная группа: ширина **1100 px**, gap **10 px** между заголовком и подзаголовком (стандарт), по центру.
- Ряд карточек: gap **10 px**, высота **225 px**, 3 карточки, каждая `flex: 1 0 0` (Fill, широкие — соответствует режиму «3 карточки» из компонента [Карточка-преимущество](../components/feature-card.md)).
- Карточка (вариант «по центру»): паддинг **20 px**, вертикальный gap **10 px**, радиус **10 px**, обводка **1 px** `Friendly Purple` (`#A677FC`), без заливки — подтверждает правило компонента «заливка или обводка, не обе».
- Иконка-плашка (уточняет геометрию для варианта «по центру», ранее не заданную): **36×36 px**, паддинг **8 px**, радиус **8 px**, глиф **24×24 px**, по центру.

## 5. Типографика

- Заголовок — **H2** (Google Sans Flex Medium 500, 44 px, 120%), белый, по центру.
- Подзаголовок — **Body Regular** (Inter Regular, 18 px, 140%), непрозрачность 90% (см. [Типографика](../foundations/typography.md)), белый.
- Заголовок карточки — **Body Semibold** (Inter Semi Bold, 18 px), белый, по центру.
- Текст карточки — **Body Small** (Inter Regular, 16 px), непрозрачность 90%, белый, по центру.

## 6. Цвета и варианты

- Фон контейнера — `Midnight Ink` (`#251E49`) — как в [Metaball Sidebar Slider](metaball-slider.md), тёмная тема.
- Обводка карточки и фон иконки-плашки — `Friendly Purple` (`#A677FC`, `accent/brand`); глиф — белый.
- Весь текст — белый (`Pure White`).

## 9. Правила контента

- Текст заголовка, подзаголовка и трёх карточек — содержимое конкретного примера («Secure cloud infrastructure», «Data encryption», «Identity and access controls»), не обязательный состав блока.
- Число карточек (3, Fill) — один из двух режимов компонента [Карточка-преимущество](../components/feature-card.md); шесть карточек (Fixed) в этом примере не показаны.

## 10. Связанные компоненты и токены

- [Карточка-преимущество](../components/feature-card.md) (вариант «по центру», 3 карточки) — этот пример восполняет геометрию иконки/заголовка для варианта.
- [Заголовочная группа](../components/heading-group.md).
- Midnight Ink (`#251E49`), Friendly Purple (`#A677FC` / `accent/brand`) — [Цвета и градиенты](../foundations/colors.md).
- Радиус 40 px (контейнер, новое значение), 10 px (карточка, иллюстрация), 8 px (иконка-плашка) — [Радиусы и обводки](../foundations/radii-strokes.md).

## 11. Проверка

- Контейнер: радиус 40, паддинг 20/60, тёмный фон `#251E49`.
- Иллюстрация: 1100×232, радиус 10.
- Ряд карточек: gap 10, высота 225, 3×Fill.
- Карточка: паддинг 20, gap 10, радиус 10, обводка 1px `#A677FC`, без заливки.
- Иконка-плашка: 36×36, паддинг 8, радиус 8, глиф 24×24, фон `#A677FC`, белый глиф.
- Весь текст — белый; подзаголовок и текст карточек — непрозрачность 90%.
