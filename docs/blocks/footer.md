# Footer

## 1. Назначение

Подвал страницы: аккордеон разделов сайта, соцсети, поиск, ссылки на приложения (App Store/Google Play), юридические ссылки и копирайт.

## 2. Источник и статус спецификации

Источник: [Untitled, node 51:3795 «footer»](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=51-3795) — содержит два состояния мобильной версии (320 px):

- [node 51:3558](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=51-3558) «Footer mobile 320» — все пункты аккордеона закрыты.
- [node 51:3667](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=51-3667) «Footer mobile 320 - Pricing open» — пункт «Pricing» раскрыт.

Десктопная версия в этом узле представлена только свёрнутым символом («Footer», 1600×820 px, id 51:3374) — его внутреннее содержимое не раскрыто в этом файле (вероятно, компонент из отдельной библиотеки). Статус: **мобильная версия — полная спецификация; десктопная версия не задана**, кроме габарита символа.

## 3. Структура

Вертикальный стек (gap **24 px**): AccordionList → Bottom (соцсети + поиск) → Container (кнопки App Store/Google Play) → LegalAndCopyright.

## 4. Геометрия

- Контейнер (мобильный): паддинг **16 px** по бокам, **24 px** сверху/снизу, gap **24 px** между секциями.
- **AccordionList** — 10 пунктов на всю ширину: Product, Pricing, Implementation, Help, Apps, AI, Use cases, Compare to, New to Bitrix24?, SEO section. Каждый пункт: горизонтальный ряд `justify-between`, паддинг по вертикали **12 px**, разделитель снизу — обводка **0.5 px** `rgba(177,177,177,.7)`, иконка `chevron-down` **16×16 px** справа.
  - Раскрытый пункт «Pricing»: шеврон разворачивается вверх (`chevron-up`), под строкой появляется список из буллетов (в примере — 2: «Cloud», «On-Premise»), каждый: точка **6×6 px** + текст, отступ слева **12 px**, между буллетами — **28 px**. Раскрытие остальных пунктов не показано — не придумывать их содержимое.
- **Bottom** (ширина **288 px**, gap **16 px**):
  - Ряд соцсетей: 6 иконок-ссылок (Facebook, Telegram, YouTube, Instagram, LinkedIn, Pinterest), у каждой правый отступ **20 px**; иконки разных пропорций (ширина 11–25 px, высота ≈22 px) — сохранять исходные пропорции ассетов, не унифицировать размер.
  - Поле поиска: пилюля, обводка **1 px** `rgba(46,41,41,.7)`, радиус **35 px**, непрозрачность контейнера **85%**; плейсхолдер «Search» — непрозрачность **70%**; иконка поиска **20×20 px** справа, отступ 15 px от края.
- **Container** (кнопки приложений): по центру, перенос строк разрешён (`flex-wrap`); кнопка App Store — **119.66×40 px**, кнопка Google Play — **135×40 px**, между ними отступ (паддинг по 4 px с каждой стороны + 10 px снизу у каждой).
- **LegalAndCopyright** (ширина **296 px**, gap **12 px**):
  - Юридические ссылки в ряд с переносом: Legal, Terms, Privacy, Security, Abuse — gap **16 px** по горизонтали / **10 px** по вертикали.
  - Копирайт — отдельная строка под ссылками.

## 5. Типографика

Первое подтверждённое использование именно **мобильных** текстовых стилей в системе (см. [Типографика](../foundations/typography.md)):

- Пункты аккордеона: **Mobile / Body Small Semibold** — Inter Semi Bold, 14 px, 140% (совпадает с размером Body Small Mobile из общей таблицы).
- Юридические ссылки: **Mobile / Caption Semibold** — Inter Semi Bold, 12 px, 140% (совпадает с размером Caption Mobile), непрозрачность **70%**.
- Копирайт: Inter Regular, 14 px, непрозрачность **50%**.
- Плейсхолдер поиска: Inter Regular, 14 px.
- Правило «Desktop Body/Body Small — 90% непрозрачности» ([Типографика](../foundations/typography.md)) сюда не относится — это мобильные размеры, и непрозрачности здесь свои для каждого элемента (70%/50%/85%), не связанные с тем правилом.

## 6. Цвета и варианты

- Фон (мобильный): линейный градиент снизу вверх — белый внизу → `Soft Cloud` (`#F4F4F4`) наверху.
- Текст пунктов аккордеона и юридических ссылок — `text/primary` (`#251E49`).
- Обводка разделителей между пунктами — `rgba(177,177,177,.7)` — новый нейтральный цвет вне палитры, не встречался раньше.
- Обводка поля поиска — `rgba(46,41,41,.7)` — тоже новый нейтральный цвет вне палитры.

## 7. Состояния и поведение

- Каждый пункт аккордеона открывается/закрывается независимо; шеврон разворачивается на 180° при раскрытии.
- Только раскрытие «Pricing» показано в источнике; поведение и содержимое остальных пунктов при раскрытии — не задано, не придумывать.

## 8. Адаптивность

Известна только мобильная версия (320 px). Десктопная версия не задана этим источником.

## 9. Правила контента

- Состав пунктов меню, соцсетей, юридических ссылок и текст копирайта («© 2026 Alaio») — контент конкретного примера.
- Раскрытый список буллетов под «Pricing» («Cloud», «On-Premise») — содержимое примера, не универсальный набор.

## 10. Связанные компоненты и токены

- `bg/secondary` (`#F4F4F4` как один из стопов градиента), `text/primary` (`#251E49`).
- Мобильные текстовые стили Body Small (14 px) и Caption (12 px) — [Типографика](../foundations/typography.md).
- Новые цвета `rgba(177,177,177,.7)` (разделители) и `rgba(46,41,41,.7)` (обводка поиска) — токенов нет.

## 11. Проверка

- Мобильный контейнер: паддинг 16/24, gap 24 между секциями.
- Аккордеон: 10 пунктов, паддинг-y 12, разделитель 0.5px, шеврон 16×16.
- Bottom: 288 px, gap 16; соцсети — 6 иконок с отступом 20; поиск — пилюля, радиус 35, обводка 1px.
- Кнопки приложений: App Store 119.66×40, Google Play 135×40.
- LegalAndCopyright: 296 px, gap 12; ссылки — gap 16/10, непрозрачность 70%; копирайт — непрозрачность 50%.
- Десктопная версия — не проверять по этой странице, геометрия не задана.
