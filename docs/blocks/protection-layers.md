**Неполная спецификация** — блок упомянут только фрагментарно, в разделе о реализации иконок в коде. Полная композиция (расположение карточек, их размеры, цвета, типографика) в источниках не описана — не придумывать недостающие параметры.

# Protection at every layer

## 1. Назначение

Не задано (композиция и назначение блока в источниках не описаны; известно только, что это шесть карточек-слоёв с иконками).

## 2. Источник и статус спецификации

Единственное упоминание — раздел «Иконки в коде» кодовой реализации (см. [Иконки](../foundations/icons.md)). Отдельного Figma-узла не зафиксировано. Статус: неполная спецификация.

## 3. Структура

Шесть карточек-слоёв («шесть карточек слоёв»). Расположение (сетка/ряд), состав каждой карточки за пределами иконки — Не задано.

## 4. Геометрия

- Иконка-плашка: **36×36**, радиус **8 px** — совпадает со ступенью «иконка + подпись» из [Радиусов и обводок](../foundations/radii-strokes.md).
- Глиф внутри — **24×24** (общее правило, см. [Иконки](../foundations/icons.md)).
- Остальная геометрия карточек — Не задано.

## 5. Типографика

Не задано.

## 6. Цвета и варианты

Иконка: фиолетовая плашка `#A677FC` + белый глиф `#FFFFFFEB` (см. [Иконки](../foundations/icons.md)). Цвет самой карточки, фона блока — Не задано.

## 7. Состояния и поведение

Не задано.

## 8. Адаптивность

Не задано.

## 9. Правила контента

Смысловой подбор иконок для карточек:

| Карточка (смысл) | Иконка |
|---|---|
| Шифрование | `Lock 2` |
| Изоляция данных | `Database` |
| Защита приложений | `Apps` |
| DDoS | `Bug` |

Дополнительно упомянуты иконки `Cloud with check`, `Glasses`, `Lock`, `Fingerprint`, `Search`, `Code dots` — источник перечисляет их в общем списке для этого блока, но явного соответствия «иконка → конкретная из шести карточек» для них не даёт. Не приписывать им конкретную карточку без источника.

## 10. Связанные компоненты и токены

[Иконки](../foundations/icons.md) — цветовая пара и радиус плашки.

## 11. Проверка

Проверять можно только иконку-плашку (36×36, радиус 8, `#A677FC` + `#FFFFFFEB`) и смысловой список из раздела 9. Остальные параметры блока не заданы источником — не проверять и не достраивать самостоятельно.
