# Блоки

Готовые переиспользуемые секции страницы, собранные из компонентов и общих правил из «Основ». Цветовые/вариантные различия внутри одного блока (например, фон карточки в metaball) описаны на его собственной странице, а не выносятся отдельными файлами.

| Блок | Содержание и варианты | Статус |
|---|---|---|
| [Хедер](header.md) | Логотип, навигация, действия; sticky-поведение | Задан по кодовой реализации |
| [Хедер (Figma)](header-figma.md) | Та же секция по Figma-узлу: полный состав меню, поиск, вход, язык | Полная спецификация; часть значений расходится с «Хедер» |
| [Hero](hero.md) | Заголовок, подзаголовок, фоновая анимация | Частичная спецификация |
| [Блок с чипами](chips-block.md) | Заголовок + ряд чипов + CTA; направления CRM, Tasks, Collaboration, Brand gradient | Полная спецификация |
| [Слайдер с верхним меню](top-menu-slider.md) | Заголовок, вкладки, превью продукта, CTA; светло-лавандовый и светло-серый цветовые варианты | Полная спецификация |
| [Слайдер с боковым меню — Metaball](metaball-slider.md) | Тёмный блок, боковое меню (4 пункта), две панели контента, соединяющие «метабол»-формы | Полная спецификация |
| [Партнёры](partners.md) | Изображение слева, заголовок/текст/Secondary CTA справа | Полная спецификация |
| [FAQ](faq.md) | Заголовок + список раскрывающихся вопросов | Полная спецификация (композиция); пункт — см. [компонент](../components/faq-item.md) |
| [Protection at every layer](protection-layers.md) | Упомянут только фрагментарно (иконки шести карточек-слоёв) | Неполная спецификация |
| [Слайдер с буллетами](bullet-slider.md) | Вкладки сверху переключают слайд и дублируются точками пагинации снизу; пример — «AI security in Bitrix24» (CoPilot/MCP/Vibecode) | Полная спецификация (все 3 вкладки примера) |

Перед созданием нового файла — проверить, нет ли уже подходящей страницы среди этого списка или среди [компонентов](../components/README.md).
