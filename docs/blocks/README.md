# Блоки

Готовые переиспользуемые секции страницы, собранные из компонентов и общих правил из «Основ». Цветовые/вариантные различия внутри одного блока (например, фон карточки в metaball) описаны на его собственной странице, а не выносятся отдельными файлами.

| Блок | Содержание и варианты | Статус |
|---|---|---|
| [Header (Figma)](header-figma.md) | Логотип, навигация (меню, поиск, вход, язык), CTA | Полная спецификация — актуальный источник геометрии и цвета |
| [Header](header.md) | Sticky-поведение и hover-состояния хедера (по кодовой реализации) | Дополняет «Header (Figma)»; своей геометрии не задаёт |
| [Hero](hero.md) | Заголовок, подзаголовок, фоновая анимация | Частичная спецификация |
| [Chips Block](chips-block.md) | Заголовок + ряд чипов + CTA; направления CRM, Tasks, Collaboration, Brand gradient | Полная спецификация |
| [Top Menu Slider](top-menu-slider.md) | Заголовок, вкладки, превью продукта, CTA; светло-лавандовый и светло-серый цветовые варианты | Полная спецификация |
| [Metaball Sidebar Slider](metaball-slider.md) | Тёмный блок, боковое меню (4 пункта), две панели контента, соединяющие «метабол»-формы | Полная спецификация |
| [Partners](partners.md) | Изображение слева, заголовок/текст/Secondary CTA справа | Полная спецификация |
| [FAQ](faq.md) | Заголовок + список раскрывающихся вопросов | Полная спецификация (композиция); пункт — см. [компонент](../components/faq-item.md) |
| [Card Frame](card-frame.md) | Заголовок + иллюстрация + 3 карточки-преимущества (вариант «по центру»); 3 цветовых варианта (тёмный, светлый с картинкой, светлый с обводкой); пример — «AI security is a shared responsibility» | Полная спецификация |
| [Card Frame Scroll](card-frame-scroll.md) | Заголовок + прокручиваемый ряд из 6 карточек-преимуществ + точки пагинации + CTA; пример — «Protection at every layer» | Полная спецификация |
| [Footer](footer.md) | Аккордеон разделов, соцсети, поиск, ссылки на приложения, юридические ссылки | Полная спецификация (только мобильная версия) |
| [Bullet Slider](bullet-slider.md) | Вкладки сверху переключают слайд и дублируются точками пагинации снизу; пример — «AI security in Bitrix24» (CoPilot/MCP/Vibecode) | Полная спецификация (все 3 вкладки примера) |
| [Customer Stories Slider](customer-stories-slider.md) | Заголовок + бейджи наград + ряд карточек-кейсов + стрелка прокрутки + CTA | Полная спецификация (одно состояние) |

Перед созданием нового файла — проверить, нет ли уже подходящей страницы среди этого списка или среди [компонентов](../components/README.md).
