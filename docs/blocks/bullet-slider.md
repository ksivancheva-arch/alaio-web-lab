# Bullet Slider

Блок — горизонтальный слайдер: вкладки сверху переключают контент и одновременно служат индикатором текущего слайда, а точки пагинации (буллеты) снизу дублируют ту же позицию. Пример в источнике — секция **«AI security in Bitrix24»** с вкладками CoPilot / MCP / Vibecode; это название и состав конкретного примера, а не блока — сам блок не привязан к теме AI/безопасности.

## 1. Назначение

Универсальный паттерн «вкладки сверху + буллеты снизу» для слайдера, где каждая вкладка показывает свой контент (в разобранном примере — заголовок, текст, иллюстрация, три карточки-преимущества и CTA). При прокрутке страницы секция использует Scroll Pinning — см. раздел 7.

## 2. Источник и статус спецификации

Источник: [Untitled](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled) — три состояния одного блока (пример «AI security in Bitrix24»):

- [node 44:1616](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=44-1616) «Слайдер 1» — активна вкладка CoPilot.
- [node 44:1768](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=44-1768) «Слайдер 2» — активна вкладка MCP.
- [node 49:2252](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=49-2252) «Слайдер 3» — активна вкладка Vibecode.

Статус: механика блока (вкладки ↔ буллеты, структура слайда) подтверждена всеми тремя состояниями примера. Иллюстрация вкладки Vibecode в источнике — незалитый плейсхолдер (см. раздел 6), не финальный визуал. Раньше этот блок был известен в документации только по одному упоминанию в [Радиусах и обводках](../foundations/radii-strokes.md) («карточки в AI-секции», пример ступени радиуса 10 px, без привязки к блоку) — это тот же блок, теперь с полной спецификацией.

Дополнительно найден более новый инстанс того же блока на другой части страницы — [node 105:5338 «Bullet Slider»](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=0-1). Он отличается от трёх состояний выше по нескольким пунктам (см. разделы 4–7) и **дополнительно включает секцию [Card Frame](card-frame.md) сразу после кнопки и точек пагинации** — то есть в этой сборке Bullet Slider заканчивается встроенным блоком Card Frame, а не только своей собственной кнопкой. Обе версии зафиксированы; какая из них актуальнее для реализации — не решено, см. [открытые вопросы](../design-system-open-questions.md).

## 3. Структура

Вертикальный стек (gap **40 px** между всеми элементами этого уровня, включая точки пагинации):

1. Заголовочная группа (H1 + подзаголовок, по центру).
2. Ряд вкладок-пилюль, дублирующих слайды (в примере — 3: CoPilot / MCP / Vibecode).
3. Внутренняя карточка с обводкой — содержимое текущего слайда: заголовок H3 + текст → иллюстрация → ряд карточек-преимуществ (3 или 4, см. раздел 4) → CTA. Это состав содержимого слайда в разобранном примере, а не обязательная форма для любого использования этого блока.
4. Точки пагинации (по числу вкладок), под карточкой.
5. В инстансе node 105:5338 — дополнительно секция [Card Frame](card-frame.md) (вариант «светлый с обводкой») сразу после кнопки, как завершение блока. В трёх исходных состояниях (node 44:1616/44:1768/49:2252) этой секции нет.

## 4. Геометрия

- Внешний контейнер: паддинг **60 px** сверху/снизу (в состояниях node 44:xxxx/49:2252), радиус **30 px** (ступень «карточка секции», [Радиусы и обводки](../foundations/radii-strokes.md)). ⚠ В инстансе node 105:5338 у контейнера задан только верхний паддинг (**60 px** сверху, нижний явно не задан — видимо, роль нижнего отступа теперь играет паддинг встроенной секции Card Frame, см. раздел 3, пункт 5).
- Заголовочная группа: ширина **1100 px**, gap **10 px** между заголовком и подзаголовком (стандарт).
- Ряд вкладок: gap **12 px** между вкладками (состояния node 44:xxxx/49:2252) — совпадает с уже задокументированным вариантом «верхнее меню, лавандовый фон» — см. [Вкладки меню](../components/menu-tabs.md), отдельно здесь не повторяется. Начертание текста вкладки — **Semi Bold 600** у активной, **Regular 400** у неактивной (правило компонента). В состояниях MCP и Vibecode этого блока активная вкладка в источнике оформлена как Bold 700 — это несоответствие конкретных узлов Figma правилу, а не отдельный вариант начертания; при реализации использовать Semi Bold 600. ⚠ В инстансе node 105:5338 вкладки оформлены совсем иначе — активная вкладка залита **сплошным** `Friendly Purple` (`#A677FC`) с иконкой на `Creative Violet` (`#7438E3`) и **белым** текстом Semibold, а неактивные — на белом фоне с иконкой на `Lavender Mist`, текст слева (не по центру), Regular. Это новый, ранее не задокументированный цветовой вариант вкладок верхнего меню — добавлен в [Вкладки меню](../components/menu-tabs.md#6-цвета-и-варианты). Состав вкладок здесь тоже другой: «CoPilot and AI» (иконка Bitrix GPT), «AI with MCP», «Vibecode platform» — вместо «CoPilot» / «MCP» / «Vibecode» коротких подписей.
- Внутренняя карточка (содержимое слайда): обводка **1 px**, радиус **30 px**, ширина **1200 px**, паддинг **20 px сверху / 30 px снизу** — асимметрично, отдельное значение именно для этой карточки (не 60/60, как у карточки Top Menu Slider). Gap **40 px** между колонкой контента и CTA (стандартное правило «от контента до кнопки»).
- Колонка контента слайда: ширина **1100 px**, gap **20 px** между заголовком, иллюстрацией и рядом карточек — отдельное значение для этого блока (не 40 px, как в общем правиле «группа → следующий элемент»).
- Иллюстрация: ширина слота — **1100 px** (фиксированная), высота — **переменная**; в состояниях node 44:xxxx/49:2252 высота — **232 px**, в инстансе node 105:5338 — **247 px**. Оба значения — измерения конкретной иллюстрации, не константа блока; переменная высота слота подтверждена дважды независимо. Радиус слота — **10 px** (ступень «мелкий блок с текстом» из [общей таблицы радиусов](../foundations/radii-strokes.md)), одинаково во всех примерах.
- Ряд карточек-преимуществ соответствует компоненту [Карточка-преимущество](../components/feature-card.md). В состояниях node 44:xxxx/49:2252 измеренные значения отличались от канонического правила в двух пунктах (иконка 30×30 px вместо 36×36 px, gap ряда 17 px вместо 10 px). В инстансе node 105:5338 иконка-плашка **исправлена до 36×36 px** (совпадает с правилом компонента), но **gap ряда остаётся 17 px** (не 10 px) — расхождение по gap не устранено. См. [открытые вопросы](../design-system-open-questions.md).
- Число карточек — **3** в состояниях CoPilot и MCP, **4** в состоянии Vibecode, **3** в инстансе node 105:5338 — не фиксированное число, а свойство конкретного слайда; ширина каждой карточки пересчитывается так, чтобы ряд заполнял 1100 px.
- Карточка-преимущество: фон белый, радиус **10 px** (ступень «мелкий блок с текстом», совпадает с общей таблицей радиусов), паддинг **20 px**, gap **10 px** между строкой «иконка+заголовок» и текстом — паддинг и внутренний gap совпадают с компонентом. Минимальная высота карточки — **222 px** (состояния MCP/Vibecode) или **225 px** (инстанс node 105:5338, ближе к 222, чем к принципиально другому значению) — измерения примеров, не константа. В состоянии CoPilot высота карточек растянута под фиксированную высоту колонки контента (614 px) — тоже измерение примера. ⚠ В инстансе node 105:5338 у карточек дополнительно появилась тень `Sh1` (см. [Card Frame](card-frame.md#4-геометрия) для описания стиля тени) — там же, где раньше теней не было; см. [открытые вопросы](../design-system-open-questions.md).
- Иконка-плашка в карточке: **30×30 px** в состояниях node 44:xxxx/49:2252 (нестандартное значение), **36×36 px** в инстансе node 105:5338 (совпадает с правилом компонента), радиус **8 px** (ступень «иконка + подпись», [Радиусы и обводки](../foundations/radii-strokes.md)). Глиф внутри — **24×24 px** (общее правило, см. [Иконки](../foundations/icons.md)); в состояниях node 44:xxxx/49:2252 измерен как ≈23.33×23.33 px — техническая неточность макета (округление в Auto Layout), не отдельное значение; в инстансе node 105:5338 измерен ровно 24×24 px.
- CTA: переиспользуемая кнопка Secondary — см. [Кнопки](../components/buttons.md).
- Точки пагинации: 3 круга **12×12 px**, gap **12 px** между ними (группа **60×12 px** целиком) — число точек равно числу вкладок примера, не фиксированная константа блока.

## 5. Типографика

- Заголовок (H1): Google Sans Flex Medium 500, 54 px, 120% — без Accent-начертания. Цвет `text/primary` (`#251E49`).
- Подзаголовок: Inter **Medium 500**, 18 px, 140%, `opacity: .8`. Тот же паттерн «Medium + непрозрачность 80%», что и в [Hero](hero.md) — встречается уже как минимум в двух блоках, не считать особенностью только одного из них; общее правило подзаголовков (Regular 400, полная непрозрачность, см. [Заголовочная группа](../components/heading-group.md)) при этом не меняется — это альтернативный, тоже наблюдаемый стиль вводного подзаголовка, а не нарушение.
- Внутри карточки (содержимое слайда) — заголовок **H3** (Google Sans Flex Medium 500, 32 px, 120%) и текст под ним (Inter Regular, 18 px, 140%, непрозрачность 90% — Desktop Body, см. [Типографика](../foundations/typography.md)) — цвет `text/primary` (`#251E49`), как и весь остальной текст блока. В узлах Figma эти два элемента извлечены с цветом `#2E2929` — это неточность конкретных узлов, не отдельное правило; текст всегда `#251E49`.
- Заголовок карточки-преимущества: **Body Semibold** (Inter Semi Bold, 18 px), непрозрачность 90%, цвет `text/primary`.
- Текст карточки-преимущества: Inter Regular, 16 px (**Body Small**), непрозрачность **90%** (правило стиля, см. [Типографика](../foundations/typography.md) — ранее здесь стояло измеренное значение 80%, приведено к общему правилу 16 сентября 2026), цвет `text/primary`.

## 6. Цвета и варианты

- Внешний фон — линейный градиент сверху вниз, от `Lavender Mist` (`#F4EEFF`) к белому.
- Обводка внутренней карточки — `copilot/200` (`#E3D8FC`) в состояниях node 44:xxxx/49:2252 — цвет не меняется вместе с активной вкладкой в этих состояниях.
- Иконка-плашка карточки-преимущества: фон **`#2E2929`** в состояниях node 44:xxxx/49:2252 (новый цвет, отдельного токена нет — не путать с Midnight Ink `#251E49`), белый глиф. ⚠ В инстансе node 105:5338 этот же элемент использует правильный токен **`Midnight Ink` (`#251E49`)**, а не `#2E2929` — похоже на исправление в источнике; см. [открытые вопросы](../design-system-open-questions.md).
- Точки пагинации сгруппированы Figma в один экспортированный SVG-ассет — точные HEX из кода не извлечены. По скриншоту: активная точка — тёмно-фиолетовая (похоже на `accent/brand` `#A677FC`), неактивные — светло-лавандовые. Не подтверждено метаданными — не считать точным значением.
- **Цветовая тема блока не зафиксирована как единственная.** По прецеденту [Top Menu Slider](top-menu-slider.md) (лавандовый/серый фон) и [Информационного чипа](../components/chip.md) (обводка по направлению продукта) у этого блока тоже предполагается несколько цветовых вариантов — например, серый, синий или другой оттенок из палитры Alaio, выбираемый по теме конкретного использования блока. Во всех трёх разобранных состояниях примера подтверждён только один вариант — лавандовый фон + обводка `copilot/200` (цвет темы примера, «AI/CoPilot», а не блока как такового; обводка не меняется даже на вкладке Vibecode). Конкретные HEX для серого/синего варианта источником не заданы — не придумывать.
- Иллюстрация вкладки Vibecode в источнике — шахматный плейсхолдер отсутствующего изображения (стандартная заглушка Figma для незалитого фона), не финальный визуал. Не переносить сам плейсхолдер как дизайн-решение и не придумывать, как должна выглядеть настоящая иллюстрация.

## 7. Состояния и поведение

- Вкладки переключают контент слайда (в примере — заголовок H3, текст, иллюстрацию, карточки-преимущества и текст CTA). Активная/неактивная вкладка — по правилам [Вкладок меню](../components/menu-tabs.md), с оговоркой по начертанию — см. раздел 4.
- Точки пагинации под карточкой дублируют позицию активной вкладки (в состоянии CoPilot активна 1-я точка, в MCP — 2-я, в Vibecode — 3-я) — то есть буллеты не независимый слайдер, а визуальный индикатор той же вкладки.
- В разобранном примере иллюстрация полностью иной композиции в каждом состоянии (CoPilot — статичная картинка со щитом и всплывающими сообщениями; MCP — компоновка из логотипа Alaio, соединительных линий и мини-карточек с логотипами внешних сервисов: Claude, Notion, Perplexity, GitHub, ChatGPT; Vibecode — незалитый плейсхолдер, см. раздел 6). Единого визуального паттерна иллюстрации не задано.
- **Scroll Pinning** — фиксация секции при прокрутке. Блок закрепляется на экране, а дальнейший скролл переключает его слайды (вкладки/буллеты) вместо обычной прокрутки страницы. Когда последовательность слайдов заканчивается, блок открепляется и страница продолжает прокручиваться как обычно. Точные параметры (порог срабатывания, привязка скролла к смене слайда 1:1 или с накоплением, поведение при прокрутке назад) источником не заданы — Не задано.

## 8. Адаптивность

Не задано.

## 9. Правила контента

- «AI security in Bitrix24» и вкладки CoPilot / MCP / Vibecode — название и состав конкретного примера, не обязательное содержимое или тема блока.
- Тексты заголовков, подзаголовков, карточек и CTA — контент этого примера, не универсальные формулировки блока.
- Список внешних сервисов на иллюстрации MCP (Claude, Notion, Perplexity, GitHub, ChatGPT) — содержимое конкретного примера.
- Число карточек-преимуществ (3 или 4) и их состав — часть конкретного слайда, не ограничение блока.
- Иллюстрация вкладки Vibecode в источнике не заполнена (плейсхолдер) — не придумывать её содержимое.

- `#2E2929` — новое значение для фона иконки-плашки, токена нет.

## 11. Проверка

- Внешний контейнер: радиус 30, паддинг 60/60, gap 40 между всеми элементами верхнего уровня.
- Вкладки: gap 12, геометрия/цвета/начертание — по [Вкладкам меню](../components/menu-tabs.md) (активная — Semi Bold 600, даже там, где в исходных узлах Figma по ошибке стоит Bold 700); число вкладок = числу точек пагинации.
- Внутренняя карточка (слайд): обводка 1 px `copilot/200`, радиус 30, паддинг 20/30, ширина 1200.
- Колонка контента слайда: 1100 px, gap 20.
- Карточки-преимущества: радиус 10, паддинг 20, иконка-плашка 30×30 радиус 8, фон `#2E2929`; число карточек — 3 или 4 по слайду.
- Точки пагинации: 12×12, gap 12, активная точка = индекс активной вкладки (1, 2 или 3 в разобранных состояниях).
- H3/текст внутри карточки — цвет `text/primary` (`#251E49`); фон иконки-плашки — `#2E2929`.
- Иллюстрация: ширина слота 1100, радиус 10 во всех состояниях; высота переменная (232 в разобранном примере — не константа).
- Глиф внутри иконки-плашки — 24×24, не ≈23.33×23.33 (измерение конкретных узлов).
