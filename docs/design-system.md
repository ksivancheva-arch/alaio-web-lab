# Alaio — дизайн-система

Согласованные правила web-design lab для `ksivancheva-arch/alaio-web-lab`: визуальные принципы, цвета, типографика, иконки, отступы, переиспользуемые компоненты и готовые блоки страниц — разбираются из Figma и фиксируются здесь как правила. Не собирать абстрактные демо-компоненты с нуля — см. [Визуальные принципы](foundations/principles.md).

## Разделы

- **[Основы](foundations/README.md)** — визуальные принципы, цвета и градиенты, типографика, сетка/контейнеры/отступы, радиусы и обводки, иконки, источники и работа с токенами.
- **[Компоненты](components/README.md)** — переиспользуемые элементы: кнопки, информационный чип, вкладки меню, пункт FAQ, заголовочная группа.
- **[Блоки](blocks/README.md)** — готовые секции страницы, собранные из компонентов и правил основ.
- **[Открытые вопросы](design-system-open-questions.md)** — противоречия, незавершённый перенос из Figma и другие решения, которые ещё предстоит принять.
