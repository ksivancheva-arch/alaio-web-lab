# Открытые вопросы

Противоречия, незавершённый перенос из Figma и другие решения, которые ещё предстоит принять. Список не заполняется предположениями — только зафиксированными фактами и ссылками на источники.

## Противоречия (требуют решения)

1. **Line-height кнопки.** Общий стиль **Button** в [Типографике](foundations/typography.md) задаёт line-height **140%**. Компонент [Кнопки](components/buttons.md), вариант Secondary в блоке [Партнёры](blocks/partners.md), зафиксирован явным решением с line-height **120%** для того же шрифта (Google Sans Flex Semibold 18 px). Решение отложено: правила кнопок будут выделены в отдельный набор правил — до этого момента оба значения остаются в документации как есть, не трогать.

## Незавершённый перенос из Figma

- **VibeCode.** Переменная `product/VibeCode` и шкала `Scale/VibeCode/*` сохранены в Variables alaio-sites, хотя направление отсутствует в обновлённом BrandBook. Решение об их судьбе не принято — см. [Цвета и градиенты](foundations/colors.md).

## Новые значения без объяснения

- **Цвет `#2E2929`.** В блоке [AI-секция](blocks/ai-section.md) заголовок H3, текст под ним и фон иконки-плашки карточек-преимуществ используют `#2E2929` — цвет, которого нет в базовой палитре ([Цвета и градиенты](foundations/colors.md)), и это единственное известное место, где текст не привязан к `text/primary` (`#251E49`). Непонятно, отдельный ли это токен (например, более тёмный нейтральный оттенок для конкретной темы блока) или технический недосмотр макета — не переносить как общее правило без подтверждения.

## Технические открытые вопросы (реализация)

- **Breakpoint Desktop/Mobile.** Конкретная точка переключения между типографикой Desktop и Mobile не согласована. См. [Типографика](foundations/typography.md).

## Неполные спецификации блоков

Упомянуты в документации, но полная структура не описана — не придумывать недостающие параметры:

- [Protection at every layer](blocks/protection-layers.md) — известна только часть иконок и геометрия иконки-плашки.
- [AI-секция](blocks/ai-section.md), вкладка **Vibecode** — структура блока и содержимое вкладок CoPilot/MCP подтверждены двумя состояниями из Figma; третья вкладка не раскрыта, её контент не задан.
- [Hero](blocks/hero.md) — известны заголовок, подзаголовок и общий принцип фоновой анимации; геометрия контейнера и остальные параметры не заданы.
- [Хедер](blocks/header.md) — задан только по кодовой реализации; типографика текста не зафиксирована.

## Необъяснённые измерения (не превращать в правило)

- Блок [Партнёры](blocks/partners.md): в исходном узле шириной 1320 px сама композиция (556 + 60 + 570 = 1186 px) не растянута на всю ширину и выровнена по левому краю; источник не объясняет оставшиеся ≈134 px справа.
