# Компонент FAQ

Спецификация переиспользуемого блока FAQ (заголовок + вертикальный список раскрывающихся вопросов).

Источник: [Untitled, node 32:692](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=32-692).

Общие правила системы (цвета, типографика, отступы) — см. [../design-system.md](../design-system.md). Здесь фиксируются только значения, специфичные для FAQ.

## 1. Структура блока

- Заголовок FAQ.
- Вертикальный список раскрывающихся пунктов.
- Каждый пункт содержит вопрос и кнопку со стрелкой справа.
- Раскрытый пункт дополнительно содержит ответ под вопросом.

## 2. Контейнер

- Ширина эталонного макета: **1320 px**.
- Высота: по содержимому (`hug`).
- Высота текущего примера — **612 px** — не фиксировать её для другого контента.
- Фон: **`#FFFFFF`** (`bg/primary`).
- Обводка отсутствует.
- Скругление внешнего контейнера: **0 px**. ⚠ Отличается от общего правила «карточка-секция = 30 px» из `design-system.md` раздела 6 — у FAQ-контейнера скругления нет вообще, это не одна из типовых карточек-секций.
- Внутренние отступы: **0 px**.
- Расстояние между заголовком и списком: **40 px** (совпадает с `spacing/content`).
- Список занимает всю ширину контейнера.
- Расстояние между пунктами: **10 px**.

## 3. Заголовок FAQ

- Шрифт: **Google Sans Flex**, начертание **500 / Medium**, размер **40 px**.
- Межстрочный интервал: **120% / 48 px**. Межбуквенный интервал: **0**.
- Цвет: **`#251E49`** (`text/primary`).
- Выравнивание: по центру. Высота: по содержимому.
- Соответствует стилю **H2** из `design-system.md` (Google Sans Flex 40 px), но **выровнен по центру** — обычные заголовки системы выравниваются по левому краю; это исключение для FAQ.

## 4. Общие правила пункта

- Ширина: заполняет контейнер (`fill`). Высота: по содержимому (`hug`).
- Скругление: **20 px**. ⚠ Не совпадает ни с одной ступенью из таблицы радиусов в `design-system.md` раздела 6 для мелких блоков (8/10 px) — у пункта FAQ собственное значение, ближе к «крупный блок» (20 px), хотя по содержимому это не крупный блок-превью.
- Горизонтальные внутренние отступы: **30 px**.
- Вопрос располагается слева, кнопка раскрытия — справа, центрирована по вертикали относительно строки вопроса.
- Ответ выравнивается по левому краю вопроса.
- В эталонном макете ширина строки с вопросом и кнопкой — **1260 px**, ширина текста вопроса и ответа — **1175 px**.
- Текст не должен попадать в область кнопки.

## 5. Закрытый пункт

- Высота в примере с однострочным вопросом: **64 px**.
- Внутренние отступы сверху/снизу: **15 px**.
- Заливка отсутствует — на белом фоне контейнера пункт выглядит белым.
- Обводка: **1 px**, внутри, `≈ #F4EEFF` (`bg/lavender`).
- Ответ скрыт. Стрелка направлена вниз.

## 6. Раскрытый пункт

- Высота зависит от длины ответа. Высота первого раскрытого пункта в источнике — **154 px** — не фиксировать это значение для другого контента.
- Внутренние отступы сверху/снизу: **20 px**.
- Фон: **`#F4F4F4`** (`bg/secondary`). Обводка отсутствует.
- Расстояние между строкой вопроса и ответом: **5 px** — самое маленькое значение gap во всей системе на сегодня (меньше, чем 7 px у бокового меню metaball-слайдера).
- Стрелка направлена вверх.

## 7. Типографика вопроса

- Inter, **500 / Medium**, **22 px**. Межстрочный интервал **120% / 26,4 px**, межбуквенный — **0**.
- Цвет: **`#251E49`** (`text/primary`). Выравнивание — по левому краю.
- Стиль одинаковый в открытом и закрытом состояниях.
- Не совпадает ни с одним готовым текстовым стилем из `design-system.md` (ближайший — H5 Inter 22 px, но там нет варианта Medium с такими межстрочными параметрами именно для этого контекста) — отдельное начертание для вопроса FAQ.

## 8. Типографика ответа

- Inter, **400 / Regular**, **18 px**. Межстрочный интервал **140% / 25,2 px**, межбуквенный — **0**.
- Цвет: **`#251E49`** (`text/primary`). Выравнивание — по левому краю.
- Совпадает с текстовым стилем **Body** (Inter Regular 18 px, 140%) из `design-system.md`.
- Высота — по содержимому. Не обрезать текст и не добавлять многоточие.

## 9. Кнопка раскрытия

### Геометрия

- Размер: **34 × 34 px**. Скругление: **8 px** (совпадает со ступенью «иконка + подпись без текста» из таблицы радиусов).
- Внутренние отступы в Figma: **5 px**. Стрелка центрирована.
- Размер векторного знака в источнике: `≈ 14 × 14,5 px`. Использовать исходную стрелку, сохраняя пропорции.

### Цветовые состояния

| Параметр | Закрытый пункт | Раскрытый пункт |
|---|---|---|
| Фон кнопки | Прозрачный | `#A677FC` (`accent/brand`) |
| Обводка | 1 px, `#A677FC` | 2 px, `#A677FC` |
| Цвет стрелки | `#A677FC` | `#FFFFFF` |
| Направление стрелки | Вниз | Вверх |

Обводка — внутри кнопки. Внешний размер в обоих состояниях — **34 × 34 px**.

## 10. Контент

В источнике показаны шесть вопросов:

1. How do I reach Bitrix24 customer support?
2. Is my data secure in Bitrix24?
3. How to upgrade my storage space?
4. How do I migrate data to Bitrix24?
5. How do I hide the Bitrix24 tools I don't need?
6. What is an HRMS?

Первый пункт показан раскрытым, остальные — закрытыми.

Это состав конкретного примера, а не обязательное количество пунктов для всех FAQ. Использовать только вопросы и ответы из утверждённого источника. **Не придумывать ответы для закрытых пунктов** — в выбранном макете их текстов нет.

## 11. Поведение и адаптивность

Макет показывает открытое и закрытое состояния, но **не задаёт**:

- возможность одновременного открытия нескольких пунктов;
- обязательное открытие первого пункта при загрузке;
- длительность и тип анимации;
- состояния наведения и фокуса;
- мобильные отступы и размеры шрифта.

Это не заданные источником параметры, а не согласованные правила — не выдавать предполагаемое поведение за утверждённое.

### Требования к реализации

Дополняют визуальную спецификацию (не связаны напрямую с Figma-макетом):

- Реализовать доступное раскрытие с клавиатуры.
- Связать управляющий элемент с ответом через `aria-expanded` и `aria-controls`.
- Обеспечить видимый фокус.
- Декоративную стрелку скрыть от скринридеров.
- При переносе вопроса увеличивать высоту пункта.
- Не допускать наложения текста на кнопку или горизонтального переполнения.

## 13. Проверка

- Ширина эталонного блока — **1320 px**.
- Между заголовком и списком — **40 px**. Между пунктами — **10 px**.
- Радиус пунктов — **20 px**. Горизонтальные отступы пунктов — **30 px**.
- Вертикальные отступы: **15 px** в закрытом состоянии, **20 px** в раскрытом.
- Между строкой вопроса и ответом — **5 px**.
- Кнопка — **34 × 34 px**, радиус — **8 px**.
- Типографика и цвета соответствуют спецификации.
- Высота списка и раскрытых пунктов зависит от контента.
