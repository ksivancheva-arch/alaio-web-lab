# Информационный чип

## 1. Назначение

Компактная пилюля «иконка + текст», отмечающая конкретную возможность/функцию. Используется рядами внутри [Блока с чипами](../blocks/chips-block.md).

## 2. Источник и статус спецификации

Источник: [Untitled, фреймы Chip CRM / Chip Tasks / Chip Collaboration / Chip brand gradient](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=0-1) — 4 цветовые реализации одного элемента. Статус: полная спецификация для этих четырёх вариантов.

## 3. Структура

Горизонтальный Auto Layout: круглая иконка слева, текст справа, gap между ними.

## 4. Геометрия

- Радиус **8 px**, паддинг **6 / 12 / 6 / 6** (top/right/bottom/left), gap **10 px** между иконкой и текстом.
- Иконка — `Solid Icon. Circle Check`, **26×26** — меньше, чем плашка 36×36 у вкладок/иконок в других компонентах ([Вкладки меню](menu-tabs.md)); отдельный, более компактный размер именно для чипа.

## 5. Типографика

Текст — **Body Semibold** (Inter Semi Bold, 18 px), непрозрачность 90% — см. [Типографика](../foundations/typography.md).

## 6. Цвета и варианты

| Направление | Фон плашки чипа | Цвет круга-иконки |
|---|---|---|
| CRM | `#EDF3FF` (CRM/50) | `#5868EE` (CRM/500) |
| Tasks | `#FCF3F8` (Tasks/50) | `#EE5EA0` (Tasks/500) |
| Collaboration | `#FFF1F1` (Collaboration/50) | `#FF7073` (Collaboration/400) |
| Brand (без направления) | `#F4EEFF` (Lavender Mist) | `#A677FC` (Friendly Purple, `accent/brand`) |

- Галочка внутри круга — белая/почти белая (`#F5F5F5`), не меняется между вариантами.
- Текст всегда `text/primary` (`#251E49`), независимо от цветового варианта.
- Радиус, паддинги, gap — одинаковы во всех вариантах; меняются только цвета фона плашки и круга по таблице.
- Цвет круга-иконки — не всегда ступень «/500» шкалы направления (у Collaboration это `/400`): это опорный цвет направления `product/<Direction>` из Variables, а не фиксированная ступень шкалы.
- Обводка карточки-блока (не самого чипа) для каждого направления — см. [Блок с чипами](../blocks/chips-block.md).

## 7. Состояния и поведение

Не задано (интерактивность чипа источником не описана — похоже на статичный информационный элемент).

## 8. Адаптивность

Не задано.

## 9. Правила контента

Иконку подбирать по смыслу — см. [Иконки](../foundations/icons.md). Количество чипов в ряду и их конкретный набор — свойство примера блока, а не ограничение самого компонента.

## 10. Связанные компоненты и токены

- `text/primary`, `accent/brand`, цветовые шкалы направлений (CRM/50, Tasks/50, Collaboration/50, Collaboration/400).
- Радиус 8 px — ступень «иконка + подпись» из [Радиусов и обводок](../foundations/radii-strokes.md).
- Используется в: [Блок с чипами](../blocks/chips-block.md).

## 11. Проверка

- Радиус 8, паддинг 6/12/6/6, gap 10.
- Иконка 26×26, `Circle Check`, галочка `#F5F5F5`.
- Текст Body Semibold, непрозрачность 90%, всегда `#251E49`.
- Фон плашки и цвет круга — по таблице цветовых вариантов.
