# Карточка-преимущество (иконка + заголовок + описание)

Два варианта: **слева** (Header Row: иконка + заголовок в строку, описание ниже) и **по центру** (содержимое выровнено по центру, без горизонтальной строки).

## 1. Назначение

Карточка «иконка + заголовок + описание» в горизонтальном ряду без переноса строк — переиспользуемый паттерн для списков преимуществ/функций (используется, например, в [Bullet Slider](../blocks/bullet-slider.md), вариант «слева»).

## 2. Источник и статус спецификации

Оба варианта заданы напрямую (правила построения карточек Alaio), не привязаны к конкретному узлу Figma. Статус: полная спецификация как канонический компонент для обоих вариантов, кроме геометрии иконки/заголовка в варианте «по центру» — она не задана источником (см. раздел 4). Единственный разобранный реальный экземпляр — карточки варианта «слева» в [Bullet Slider](../blocks/bullet-slider.md) — измерен по своему Figma-узлу и в двух пунктах отличается от канонического правила (иконка 30×30 вместо 36×36, gap ряда 17 px вместо 10 px) — см. [открытые вопросы](../design-system-open-questions.md).

## 3. Структура

**Общее для обоих вариантов:** ряд карточек — контейнер: горизонтальный Auto Layout, без переноса строк (`wrap: нет`), карточки равной ширины, заполняющие ряд.

- **Вариант «слева»:** карточка — вертикальный стек: строка заголовка (Header Row: иконка + заголовок в горизонтальный ряд) → описание.
- **Вариант «по центру»:** карточка — вертикальный стек, содержимое выровнено по центру; горизонтальной строки Header Row нет. Точная структура/геометрия иконки и заголовка для этого варианта не заданы источником.

## 4. Геометрия

**Общее для обоих вариантов**

- Ряд карточек: горизонтальный Auto Layout, spacing (gap между карточками) **10 px**, padding контейнера **0**, без переноса строк.
- Карточка: padding **20 px** со всех сторон, spacing между элементами внутри карточки **10 px**.
- Радиус всей карточки — **10 px** (ступень «мелкий блок с текстом», см. [Радиусы и обводки](../foundations/radii-strokes.md)).
- Без теней, без градиента, без вложенных карточек.
- Фон карточки — либо заливка, либо обводка, не то и другое одновременно.

**Вариант «слева» — дополнительно**

- Количество карточек определяет ширину каждой отдельной карточки (карточки делят ширину ряда поровну, с учётом gap 10 px) — число карточек не фиксировано.
- Header Row (иконка + заголовок): Auto Layout горизонтальный, spacing **10 px**, высота **50 px** (максимум). Иконка-плашка (Group): контейнер **36×36 px**; фон (Rectangle) **36×36 px**, радиус **8 px** (ступень «иконка + подпись», см. [Радиусы и обводки](../foundations/radii-strokes.md)); иконка (Instance) **24×24 px**, по центру, отступ 6 px от каждого края плашки — совпадает с общим правилом «глиф 24×24» ([Иконки](../foundations/icons.md)). Заголовок: ширина **Fill** — занимает оставшееся пространство строки после иконки.
- Описание: ширина **Fill parent**, text auto-resize **Height** — карточка растягивается по высоте под содержимое описания.

**Вариант «по центру» — дополнительно**

- Количество карточек: **3** (ширина карточки — Fill, широкие) или **6** (ширина фиксированная ≈**298 px**, узкие) — число карточек определяет, какой из двух режимов ширины используется.
- Блок описания (Frame): вертикальный Auto Layout, sizing Fill/Hug, spacing **8 px**, padding **0**.
- Описание: ширина **Fill parent** (**320 px** в примере), выравнивание текста **Center / Top**, text auto-resize **Height**.
- Геометрия иконки и заголовка для этого варианта не задана источником — Не задано.

## 5. Типографика

Заголовок и описание используют **только стили из библиотеки** — не задавать кастомные размер/начертание/интервал отдельно для карточки, в обоих вариантах.

- **Заголовок** (вариант «слева»): стиль **Body Semibold** (`Alaio/Desktop/Body Semibold`) — Inter Semi Bold, 18 px, непрозрачность 90% (см. [Типографика](../foundations/typography.md)). Для варианта «по центру» стиль заголовка не задан источником.
- **Описание** (оба варианта): стиль **Body Small** (`Desktop/Body Small`) — Inter Regular, 16 px, непрозрачность 90% (см. [Типографика](../foundations/typography.md)); в варианте «по центру» дополнительно выравнивание по центру (Center/Top). В сообщении с исходной спецификацией варианта «слева» размер также был указан как «18/16 px» — вероятно, копипаст-неточность (18 px совпадает с заголовком, а не со стилем Body Small); первичным считается названный токен `Desktop/Body Small` (16 px).

## 6. Цвета и варианты

- Иконка внутри плашки (вариант «слева») — **белая** (см. [Иконки](../foundations/icons.md)).
- Цвет фона плашки, цвет текста заголовка/описания — не заданы этим правилом как фиксированные (подбираются по контексту блока; см. пример цветов в [Bullet Slider](../blocks/bullet-slider.md)).
- Фон карточки (оба варианта, явно подтверждено для «по центру») — либо заливка, либо обводка, не оба сразу; конкретные цвета не заданы этим правилом.

## 7. Состояния и поведение

Не задано.

## 8. Адаптивность

Не задано.

## 9. Правила контента

- Иконку подбирать по теме блока — см. [Иконки](../foundations/icons.md).
- Количество карточек в ряду — свойство конкретного использования, не фиксированное число компонента: вариант «слева» не ограничен по числу карточек; вариант «по центру» рассчитан на **3 или 6** карточек (эти два значения переключают Fill/Fixed-режим ширины, см. раздел 4).

## 10. Связанные компоненты и токены

- Радиус 10 px (карточка), 8 px (иконка-плашка, вариант «слева») — [Радиусы и обводки](../foundations/radii-strokes.md).
- Глиф 24×24 (вариант «слева») — [Иконки](../foundations/icons.md).
- Стили `Body Semibold` / `Body Small`, непрозрачность 90% — [Типографика](../foundations/typography.md).
- Пример использования: [Bullet Slider](../blocks/bullet-slider.md) (карточки-преимущества, вариант «слева») — с отклонениями по иконке и gap ряда, см. раздел 2. Реального экземпляра варианта «по центру» пока не разобрано.

## 11. Проверка

**Общее:** ряд — horizontal, gap 10, padding 0, без переноса; карточка — padding 20 со всех сторон, радиус 10, фон — заливка ИЛИ обводка (не обе), без теней/градиентов/вложенных карточек.

- **Слева:** gap 10 между Header Row и описанием; Header Row — horizontal, gap 10, высота до 50 px, иконка-плашка 36×36 радиус 8, глиф 24×24 по центру (отступ 6 px), белый; заголовок — Fill, Body Semibold 18 px/90%; описание — Fill, auto-height, Body Small 16 px/90%.
- **По центру:** 3 карточки (Fill, широкие) или 6 карточек (Fixed ≈298 px, узкие); блок описания — вертикальный Auto Layout, spacing 8, padding 0; описание — Fill parent (320 px в примере), Center/Top, auto-height, Body Small 16 px/90%.
