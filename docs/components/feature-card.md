# Карточка-преимущество (иконка + заголовок + описание)

Два варианта: **слева** (Header Row: иконка + заголовок в строку, описание ниже) и **по центру** (содержимое выровнено по центру, без горизонтальной строки).

## 1. Назначение

Карточка «иконка + заголовок + описание» в горизонтальном ряду без переноса строк — переиспользуемый паттерн для списков преимуществ/функций (используется в [Bullet Slider](../blocks/bullet-slider.md), [Card Frame](../blocks/card-frame.md) и [Card Frame Scroll](../blocks/card-frame-scroll.md)).

## 2. Источник и статус спецификации

Оба варианта заданы напрямую (правила построения карточек Alaio), не привязаны к конкретному узлу Figma, но с тех пор подтверждены реальными экземплярами. Статус: полная спецификация как канонический компонент для обоих вариантов.

- Вариант **«слева»** — реальные экземпляры: карточки в [Bullet Slider](../blocks/bullet-slider.md) (измерены с отклонением от правила — иконка 30×30 вместо 36×36, gap ряда 17 px вместо 10 px, см. [открытые вопросы](../design-system-open-questions.md)) и карточки в [Card Frame Scroll](../blocks/card-frame-scroll.md) (полностью совпадают с правилом: иконка 36×36, радиус 8, глиф 24×24; 6 карточек, Fixed 298 px).
- Вариант **«по центру»** — реальный экземпляр: карточки в [Card Frame](../blocks/card-frame.md) (тоже полностью совпадают с правилом: иконка 36×36, радиус 8, глиф 24×24; 3 карточки, Fill) — этот пример впервые подтвердил геометрию иконки/заголовка для данного варианта, ранее заданную только напрямую, без Figma-примера.

## 3. Структура

**Общее для обоих вариантов:** ряд карточек — контейнер: горизонтальный Auto Layout, без переноса строк (`wrap: нет`), карточки равной ширины, заполняющие ряд.

- **Вариант «слева»:** карточка — вертикальный стек: строка заголовка (Header Row: иконка + заголовок в горизонтальный ряд) → описание.
- **Вариант «по центру»:** карточка — вертикальный стек, содержимое выровнено по центру; горизонтальной строки Header Row нет — иконка, заголовок и описание идут друг под другом, каждый по центру.

## 4. Геометрия

**Общее для обоих вариантов**

- Ряд карточек: горизонтальный Auto Layout, spacing (gap между карточками) **10 px**, padding контейнера **0**, без переноса строк.
- Карточка: padding **20 px** со всех сторон, spacing между элементами внутри карточки **10 px**.
- Радиус всей карточки — **10 px** (ступень «мелкий блок с текстом», см. [Радиусы и обводки](../foundations/radii-strokes.md)).
- Без градиента, без вложенных карточек. Тень: карточка получает тень **`Sh1`**, **если у окружающего блока есть собственный фон** (заливка контейнера секции); если у блока нет своего фона (карточки лежат прямо на фоне страницы), тени на карточках нет (решение от 17 сентября 2026). См. [Card Frame](../blocks/card-frame.md) (блок с фоном → тень) и [Card Frame Scroll](../blocks/card-frame-scroll.md) (блок без своего фона → без тени).
- Фон карточки — либо заливка, либо обводка, не то и другое одновременно. ⚠ Светлые варианты [Card Frame](../blocks/card-frame.md) используют одновременно белую заливку и тонкую (0.5 px) обводку `Soft Cloud` — расходится с этим правилом, см. [открытые вопросы](../design-system-open-questions.md).
- Иконка-плашка (оба варианта): **36×36 px**, радиус **8 px** (ступень «иконка + подпись», см. [Радиусы и обводки](../foundations/radii-strokes.md)), глиф **24×24 px** по центру — совпадает с общим правилом «глиф 24×24» ([Иконки](../foundations/icons.md)).
- Количество карточек — **3** (ширина каждой — Fill, широкие) или **6** (ширина фиксированная **298 px**, узкие). Подтверждено: вариант «по центру» с 3 картами Fill ([Card Frame](../blocks/card-frame.md)) и вариант «слева» с 6 картами Fixed ([Card Frame Scroll](../blocks/card-frame-scroll.md)); обратные комбинации (слева+3, по центру+6) пока не встречались, но правило заявлено как общее для обоих вариантов.

**Вариант «слева» — дополнительно**

- Header Row (иконка + заголовок): Auto Layout горизонтальный, spacing **10 px**, высота **50 px** (максимум). Заголовок: ширина **Fill** — занимает оставшееся пространство строки после иконки.
- Описание: ширина **Fill parent**, text auto-resize **Height** — карточка растягивается по высоте под содержимое описания.

**Вариант «по центру» — дополнительно**

- Блок описания (Frame): вертикальный Auto Layout, sizing Fill/Hug, spacing **8 px**, padding **0**.
- Описание: ширина **Fill parent** (**320 px** в примере), выравнивание текста **Center / Top**, text auto-resize **Height**.

## 5. Типографика

Заголовок и описание используют **только стили из библиотеки** — не задавать кастомные размер/начертание/интервал отдельно для карточки, в обоих вариантах.

- **Заголовок** (оба варианта): стиль **Body Semibold** (`Alaio/Desktop/Body Semibold`) — Inter Semi Bold, 18 px, непрозрачность 100% (см. [Типографика](../foundations/typography.md)); в варианте «по центру» дополнительно выравнивание по центру.
- **Описание** (оба варианта): стиль **Body Small** (`Desktop/Body Small`) — Inter Regular, 16 px, непрозрачность 100% (см. [Типографика](../foundations/typography.md)); в варианте «по центру» дополнительно выравнивание по центру (Center/Top). В сообщении с исходной спецификацией варианта «слева» размер также был указан как «18/16 px» — вероятно, копипаст-неточность (18 px совпадает с заголовком, а не со стилем Body Small); первичным считается названный токен `Desktop/Body Small` (16 px).

## 6. Цвета и варианты

- Иконка внутри плашки (оба варианта) — **белая** (см. [Иконки](../foundations/icons.md)).
- Цвет фона плашки, цвет текста заголовка/описания — не заданы этим правилом как фиксированные (подбираются по контексту блока): `#A677FC` в [Card Frame](../blocks/card-frame.md), `#251E49` в [Card Frame Scroll](../blocks/card-frame-scroll.md), `#2E2929` в [Bullet Slider](../blocks/bullet-slider.md) — три разных значения в трёх примерах, общего цвета правило не задаёт.
- Фон карточки (оба варианта, подтверждено обоими новыми примерами) — либо заливка, либо обводка, не оба сразу; конкретные цвета не заданы этим правилом.

## 7. Состояния и поведение

Не задано.

## 8. Адаптивность

Не задано.

## 9. Правила контента

- Иконку подбирать по теме блока — см. [Иконки](../foundations/icons.md).
- Количество карточек в ряду — свойство конкретного использования, не фиксированное число компонента: вариант «слева» не ограничен по числу карточек; вариант «по центру» рассчитан на **3 или 6** карточек (эти два значения переключают Fill/Fixed-режим ширины, см. раздел 4).

## 10. Связанные компоненты и токены

- Радиус 10 px (карточка), 8 px (иконка-плашка) — [Радиусы и обводки](../foundations/radii-strokes.md).
- Глиф 24×24 — [Иконки](../foundations/icons.md).
- Стили `Body Semibold` / `Body Small`, непрозрачность 100% — [Типографика](../foundations/typography.md).
- Примеры использования: [Bullet Slider](../blocks/bullet-slider.md) (вариант «слева», с отклонениями — см. раздел 2), [Card Frame Scroll](../blocks/card-frame-scroll.md) (вариант «слева», без отклонений), [Card Frame](../blocks/card-frame.md) (вариант «по центру», без отклонений).

## 11. Проверка

**Общее:** ряд — horizontal, gap 10, padding 0, без переноса; карточка — padding 20 со всех сторон, радиус 10, иконка-плашка 36×36 радиус 8 (глиф 24×24, белый), фон карточки — заливка ИЛИ обводка (не обе), без градиентов/вложенных карточек, тень `Sh1` только если у блока есть свой фон; 3 карточки (Fill) или 6 карточек (Fixed 298 px).

- **Слева:** gap 10 между Header Row и описанием; Header Row — horizontal, gap 10, высота до 50 px; заголовок — Fill, Body Semibold 18 px/100%; описание — Fill, auto-height, Body Small 16 px/100%.
- **По центру:** заголовок — Body Semibold 18 px/100%, по центру; блок описания — вертикальный Auto Layout, spacing 8, padding 0; описание — Fill parent (320 px в примере), Center/Top, auto-height, Body Small 16 px/100%.
