# Карточка-преимущество (иконка + заголовок + описание)

## 1. Назначение

Карточка «иконка + заголовок + описание» в горизонтальном ряду без переноса строк — переиспользуемый паттерн для списков преимуществ/функций (используется, например, в [Слайдере с буллетами](../blocks/bullet-slider.md)).

## 2. Источник и статус спецификации

Правило задано напрямую (правила построения карточек Alaio), не привязано к конкретному узлу Figma. Статус: полная спецификация как канонический компонент. Единственный разобранный реальный экземпляр — карточки в [Слайдере с буллетами](../blocks/bullet-slider.md) — измерен по своему Figma-узлу и в двух пунктах отличается от этого канонического правила (иконка 30×30 вместо 36×36, gap ряда 17 px вместо 10 px) — см. [открытые вопросы](../design-system-open-questions.md).

## 3. Структура

Карточка — вертикальный стек: строка заголовка (Header Row: иконка + заголовок) → описание.

Ряд карточек — контейнер: горизонтальный Auto Layout, без переноса строк (`wrap: нет`), карточки равной ширины, заполняющие ряд.

## 4. Геометрия

**Ряд карточек (контейнер)**

- Auto Layout: горизонтальный.
- Spacing (gap между карточками): **10 px**.
- Padding контейнера: **0**.
- Wrap: нет — карточки всегда в один ряд.
- Количество карточек определяет ширину каждой отдельной карточки (карточки делят ширину ряда поровну, с учётом gap 10 px) — число карточек не фиксировано.

**Карточка**

- Padding: **20 px** со всех сторон.
- Spacing между элементами внутри карточки (Header Row → описание): **10 px**.

**Header Row (иконка + заголовок)**

- Auto Layout: горизонтальный, spacing **10 px**.
- Высота: **50 px** (максимум).
- Иконка-плашка (Group): контейнер **36×36 px**; фон (Rectangle) **36×36 px**, радиус **8 px** (ступень «иконка + подпись», см. [Радиусы и обводки](../foundations/radii-strokes.md)); иконка (Instance) **24×24 px**, по центру, отступ 6 px от каждого края плашки — совпадает с общим правилом «глиф 24×24» ([Иконки](../foundations/icons.md)).
- Заголовок: ширина **Fill** — занимает оставшееся пространство строки после иконки.

**Описание**

- Ширина: **Fill parent**.
- Text auto-resize: **Height** — карточка растягивается по высоте под содержимое описания.

## 5. Типографика

- Заголовок: стиль **Body Semibold** (`Alaio/Desktop/Body Semibold`) — Inter Semi Bold, 18 px, непрозрачность 90% (см. [Типографика](../foundations/typography.md)).
- Описание: стиль **Body Small** (`Desktop/Body Small`) — Inter Regular, 16 px, непрозрачность 90% (см. [Типографика](../foundations/typography.md)). В исходном сообщении размер также упомянут как «18/16 px» — вероятно, копипаст-неточность (18 px совпадает с заголовком, а не со стилем Body Small); первичным считается названный токен `Desktop/Body Small` (16 px).
- Заголовок и описание используют **только стили из библиотеки** — не задавать кастомные размер/начертание/интервал отдельно для карточки.

## 6. Цвета и варианты

- Иконка внутри плашки — **белая** (см. [Иконки](../foundations/icons.md)).
- Цвет фона плашки, цвет текста заголовка/описания — не заданы этим правилом как фиксированные (подбираются по контексту блока; см. пример цветов в [Слайдере с буллетами](../blocks/bullet-slider.md)).

## 7. Состояния и поведение

Не задано.

## 8. Адаптивность

Не задано.

## 9. Правила контента

- Иконку подбирать по теме блока — см. [Иконки](../foundations/icons.md).
- Количество карточек в ряду — свойство конкретного использования, не фиксированное число компонента.

## 10. Связанные компоненты и токены

- Радиус 8 px (иконка-плашка) — [Радиусы и обводки](../foundations/radii-strokes.md).
- Глиф 24×24 — [Иконки](../foundations/icons.md).
- Стили `Body Semibold` / `Body Small`, непрозрачность 90% — [Типографика](../foundations/typography.md).
- Пример использования: [Слайдер с буллетами](../blocks/bullet-slider.md) (карточки-преимущества) — с отклонениями по иконке и gap ряда, см. раздел 2.

## 11. Проверка

- Ряд: horizontal, gap 10, padding 0, без переноса.
- Карточка: padding 20 со всех сторон, gap 10 между Header Row и описанием.
- Header Row: horizontal, gap 10, высота до 50 px; иконка-плашка 36×36 радиус 8, глиф 24×24 по центру (отступ 6 px), белый.
- Заголовок — Fill, Body Semibold 18 px/90%; описание — Fill, auto-height, Body Small 16 px/90%.
