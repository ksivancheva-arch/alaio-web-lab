# Компоненты

Переиспользуемые элементы интерфейса. Цветовые/контекстные варианты компонента описаны внутри его страницы, а не выносятся отдельными файлами.

| Компонент | Кратко |
|---|---|
| [Кнопки](buttons.md) | Primary CTA, Secondary, хедерная CTA |
| [Информационный чип](chip.md) | Иконка-круг + текст, 4 цветовых варианта фона/иконки |
| [Вкладки меню](menu-tabs.md) | Верхнее меню и боковое меню (metaball) — два явно различающихся варианта |
| [Пункт FAQ](faq-item.md) | Вопрос, ответ, открытое/закрытое состояние, кнопка раскрытия |
| [Заголовочная группа](heading-group.md) | Заголовок + необязательный подзаголовок, известные варианты по блокам |

Перед созданием нового файла — проверить, нет ли уже подходящей страницы среди этих пяти или среди [блоков](../blocks/README.md).
