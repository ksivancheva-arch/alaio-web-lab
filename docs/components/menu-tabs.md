# Вкладки меню

## 1. Назначение

Пункт меню «иконка + текст», переключающий отображаемый контент. В системе встречаются два явно различающихся варианта: **верхнее меню** (горизонтальный ряд вкладок) и **боковое меню** (вертикальный список, стиль metaball). Общая логика состояний одна, геометрия и часть цветов — разные.

## 2. Источник и статус спецификации

- Верхнее меню — [alaio-sites, node 190:41107](https://www.figma.com/design/mI7upMBDx8OpZ35XX4Pld9/alaio-sites?node-id=190-41107), блок [Top Menu Slider](../blocks/top-menu-slider.md); дополнительный цветовой вариант «фиолетовый активный» — [Untitled, node 105:5338](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=0-1), блок [Bullet Slider](../blocks/bullet-slider.md).
- Боковое меню — [Untitled, «слайдер с боковым меню стиль метабол»](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=0-1), блок [Metaball Sidebar Slider](../blocks/metaball-slider.md).

Статус: полная спецификация для обоих вариантов в контексте своего блока.

## 3. Структура

Оба варианта: контейнер «ряд/список пунктов» → внутри каждый пункт — иконка-плашка + текст.

- Верхнее меню: горизонтальный список пунктов.
- Боковое меню: вертикальный список пунктов, у каждого пункта собственный фон (в отличие от верхнего меню, где фон есть только у активного).

## 4. Геометрия

**Верхнее меню**

- Список: горизонтальный Auto Layout, gap **12 px** между вкладками (не 10 — отдельное правило именно для табов, не для пары кнопок).
- Пункт: горизонтальный Auto Layout, радиус **8 px**, паддинг **6 / 12 / 6 / 6**, gap **10 px** между иконкой и текстом.
- Иконка-плашка: **36×36**, радиус 8 px, паддинг 6 px со всех сторон → глиф **24×24**.

**Боковое меню**

- Список: вертикальный Auto Layout, gap **7 px** — плотнее, чем везде в системе, потому что у самих пунктов есть свой фон (fill): визуальное разделение даёт контраст плашек, а не отступ.
- Пункт: **285.5×68**, радиус 8 px, паддинг 6/12/6/6, gap 10 px между иконкой и текстом.
- Иконка-плашка: 36×36 (при активном состоянии).

## 5. Типографика

- Активная вкладка/пункт: **Semi Bold 600**.
- Неактивная вкладка/пункт: **Regular 400**.

Согласуется с общим правилом системы «Regular — база, акцент начертанием усиливается» (см. [Типографика](../foundations/typography.md)): здесь бинарный акцент — активное состояние.

- Верхнее меню — размер текста источником для самого пункта отдельно не переизмерен (см. общий стиль Body в [Типографике](../foundations/typography.md)); боковое меню — активный пункт **Body Semibold**, неактивный **Body Regular**.

## 6. Цвета и варианты

### Верхнее меню — цвет зависит от фона блока

**Светло-лавандовый блок** — фон блока `bg/lavender` (≈ `#F4EEFF`):

| Элемент | Активная вкладка | Неактивная вкладка |
|---|---|---|
| Фон плашки меню | `#FFFFFF` | `#A677FC`, непрозрачность **10%** |
| Фон области иконки | `#A677FC` | `#FFFFFF` |
| Знак внутри области иконки | `#FFFFFF` | `#A677FC` |
| Цвет текста | `#251E49` | `#251E49` |
| Начертание текста | **600 / Semi Bold** | **400 / Regular** |

**Светло-серый блок** — фон блока `#F4F4F4`:

| Элемент | Активная вкладка | Неактивная вкладка |
|---|---|---|
| Фон плашки меню | `#FFFFFF` | `#251E49`, непрозрачность **10%** |
| Фон области иконки | `#251E49` | `#FFFFFF` |
| Знак внутри области иконки | `#FFFFFF` | `#251E49` |
| Цвет текста | `#251E49` | `#251E49` |
| Начертание текста | **600 / Semi Bold** | **400 / Regular** |

**Фиолетовый активный** — встречен на лавандовом фоне блока в новейшем инстансе [Bullet Slider](../blocks/bullet-slider.md) (node 105:5338); инвертированная схема по сравнению со светло-лавандовым вариантом выше:

| Элемент | Активная вкладка | Неактивная вкладка |
|---|---|---|
| Фон плашки меню | `Friendly Purple` (`#A677FC`), сплошная заливка | `Pure White` |
| Фон области иконки | `Creative Violet` (`#7438E3`) | `Lavender Mist` (`#F4EEFF`) |
| Цвет текста | Белый | `#251E49` |
| Начертание текста | **600 / Semi Bold** | **400 / Regular** |
| Выравнивание текста | По центру | По левому краю (не по центру — отличие от других вариантов) |

Неясно, применяется ли непрозрачность 10% к чему-либо в этом варианте — в разобранном примере активная вкладка залита полностью непрозрачно, а не полупрозрачной подложкой, поэтому «неактивная-через-прозрачность» тут не про активную, а про то, что активная теперь и есть насыщенная заливка (обратная логика по сравнению со светлыми вариантами, где заливка — у неактивной). Не считать это универсальным правилом без дополнительных примеров.

Правила применения: выбирать вариант по фону блока; непрозрачность 10% — только у фона неактивной плашки (в вариантах «светло-лавандовый»/«светло-серый»); текст, область иконки и знак внутри неё — всегда 100% непрозрачности; не смешивать варианты внутри одного меню.

### Боковое меню (на тёмном фоне `#251E49`)

- **Активный:** фон белый, иконка-плашка на `accent/brand` (`#A677FC`) с белым глифом, текст тёмный (`#251E49`).
- **Неактивный (×3):** фон — `accent/brand` @ **20% прозрачности**, иконка-плашка = цвет самой карточки (`#251E49`, плашка «прячется» в фоне), текст белый.

### Общее правило непрозрачности

**10%** — на светлом фоне блока (верхнее меню, лавандовый вариант), **20%** — на тёмном фоне блока (боковое меню, Midnight Ink). Значение зависит от контраста фона блока, а не является отдельной константой для каждого варианта меню.

## 7. Состояния и поведение

- Активное/неактивное состояние определяется выбором пользователя; визуально — по таблицам цвета/начертания выше.
- Полная механика переключения (что двигается, что статично, привязка контента к выбранному пункту, а не к позиции) — часть композиции блока, см. [Metaball Sidebar Slider](../blocks/metaball-slider.md#7-состояния-и-поведение).

## 8. Адаптивность

Не задано.

## 9. Правила контента

- Иконку подбирать по смыслу — см. [Иконки](../foundations/icons.md).
- Количество вкладок/пунктов — свойство конкретного примера блока (в боковом меню разобрано 4 пункта), а не ограничение компонента.

## 10. Связанные компоненты и токены

- `bg/lavender`, `accent/brand`, `text/primary`.
- Радиус 8 px — ступень «иконка + подпись» из [Радиусов и обводок](../foundations/radii-strokes.md).
- Глиф 24×24 — [Иконки](../foundations/icons.md).
- Используется в: [Top Menu Slider](../blocks/top-menu-slider.md), [Metaball Sidebar Slider](../blocks/metaball-slider.md), [Bullet Slider](../blocks/bullet-slider.md) (вариант «верхнее меню», лавандовый фон — без изменений).

## 11. Проверка

- Верхнее меню: gap 12 между вкладками, вкладка радиус 8, паддинг 6/12/6/6, иконка-плашка 36×36 → глиф 24×24, цвет по варианту фона блока.
- Боковое меню: gap 7 между пунктами, пункт 285.5×68, радиус 8, паддинг 6/12/6/6, активный/неактивный — по таблице выше.
