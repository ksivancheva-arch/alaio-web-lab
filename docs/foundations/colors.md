# Цвета и градиенты

Использовать библиотеку BrandBook как основу цветовой схемы, сохраняя названия переменных. Источники — см. [Источники и работа с токенами](sources-tokens.md).

## Действующие правила

### Базовая палитра

| Переменная BrandBook | HEX | Назначение в макетах |
|---|---|---|
| Pure White | `#FFFFFF` | Основной фон, белые символы иконок |
| Soft Cloud | `#F4F4F4` | Нейтральные поверхности |
| Lavender Mist | `#F4EEFF` | Светлые фиолетовые подложки |
| Vanilla Glow | `#FFF2CD` | Светлые тёплые подложки |
| Honey Yellow | `#FFD972` | Жёлтый акцент |
| Friendly Purple | `#A677FC` | Базовый брендовый фиолетовый |
| Creative Violet | `#7438E3` | Насыщенный фиолетовый акцент |
| Midnight Ink | `#251E49` | Тёмный цвет библиотеки |

HEX приведены в 8-битном представлении; для точного переноса переменных использовать исходные значения Figma.

В системе нет отдельного «чёрного» цвета для текста — весь текст использует **Midnight Ink** (`#251E49`, `text/primary`), даже когда в конкретном узле Figma встречается близкий тёмно-серый оттенок (решение от 15 сентября 2026). Такие узлы — неточность конкретного макета, не повод заводить новый текстовый цвет.

### Продуктовые цвета

Актуальные названия направлений (после переименования брендом — см. историю ниже).

| Направление | HEX | Соответствующая ступень |
|---|---|---|
| CRM | `#5868EE` | CRM / 500 |
| VibeCode | `#7438E3` | VibeCode / 600 |
| AI Assistants | `#AA83F2` | AI Assistants / 400 |
| Tasks | `#EE5EA0` | Tasks / 500 |
| Collaboration | `#FF7073` | Collaboration / 400 |
| HR & Automation | `#FF9900` | HR & Automation / 500 |
| E-commerce | `#FFC800` | E-commerce / 500 |

В коллекции Colors есть шкалы 50–950 для этих семи направлений. Использовать существующие оттенки библиотеки по смыслу продукта или функции, сохраняя светлую и спокойную основу страницы. Статус переменной VibeCode — см. [открытые вопросы](../design-system-open-questions.md).

### Брендовый градиент

Перенесён как Figma Fill Style **`Alaio/Gradient/Brand`** в alaio-sites (Figma Variables не поддерживают тип «градиент», поэтому только так, не через Variables).

- Тип: линейный, горизонтальный (0°).
- Стопы: `#7438E3` (0) → `#A677FC` (0.3) → `#FF8AF3` (0.6) → `#FFD972` (1) — Creative Violet → Friendly Purple → розовый → Honey Yellow.
- Источник: раздел «Градиент» в [«Сборка Брендбука»](https://www.figma.com/design/XqTAJ4aVdOipjb6E0y0oaZ/BrandBook?node-id=2451-20645), подписан там как «Основной градиент»; в BrandBook указано, что тот же градиент используется в логотипе.
- `#FF8AF3` — новый цвет, встречается только как стоп градиента; отдельной переменной Primitives под него пока не заведено.
- Образец добавлен на страницу «02 Colors» в alaio-sites.
- Перенесён 13 сентября 2026. Решено (15 сентября 2026) не переносить остальные градиенты BrandBook — в системе используется только этот основной брендовый градиент; см. историю ниже.

## История изменений

### Синхронизация с обновлённым BrandBook (10 сентября 2026)

Сверено с разделом [«Сборка Брендбука»](https://www.figma.com/design/XqTAJ4aVdOipjb6E0y0oaZ/BrandBook?node-id=2451-20645) в BrandBook.

- Базовая палитра и шкалы 50–950 для CRM, Tasks, Collaboration, HR & Automation не изменились — HEX-значения совпадают побайтово.
- Направления **Sites** и **Copilot** переименованы брендом в **E-commerce** и **AI Assistants**; HEX и шкалы 50–950 остались прежними, изменилось только название. Переменные `Scale/Sites/*` → `Scale/E-commerce/*`, `Scale/Copilot/*` → `Scale/AI Assistants/*`, `product/Sites` → `product/E-commerce`, `product/Copilot` → `product/AI Assistants` переименованы в Variables alaio-sites вслед за брендом.
- Направление **VibeCode** в обновлённом BrandBook отсутствует (нет ни цвета, ни упоминания). Переменная `product/VibeCode` и шкала `Scale/VibeCode/*` в Variables оставлены как есть — решение о её судьбе не принято, это не команда на удаление.
- В BrandBook есть градиентная система (2 линейных hero-градиента + 8 радиальных glow-градиентов purple/yellow). Перенесён только основной брендовый градиент (см. выше). Остальные 8 радиальных glow-градиентов и второй линейный вариант (используемый в логотипе под другим углом) решено **не переносить** (15 сентября 2026) — в дизайн-системе используется только основной брендовый градиент.

### Уточнение исходного брифа

В первом брифе указаны violet `#AA83F2`, yellow `#FFD972`, dark `#242424`. Позже основой выбрана библиотека BrandBook. В ней `#AA83F2` — Copilot / 400 (ныне AI Assistants / 400), Friendly Purple — `#A677FC`, а Midnight Ink — `#251E49`.

Для новых секций ориентироваться на библиотеку. Исходный `#242424` не считать переменной Midnight Ink и не подменять им значение библиотеки.
