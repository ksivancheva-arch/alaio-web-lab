# Основы

Общие правила бренда Alaio. Действуют по умолчанию для всех компонентов и блоков; на страницах компонентов/блоков фиксируются только уточнения и отличия, специфичные для них.

- [Визуальные принципы](principles.md) — цель системы и стилевые ориентиры.
- [Цвета и градиенты](colors.md) — базовая палитра, продуктовые цвета, брендовый градиент, история изменений BrandBook.
- [Типографика](typography.md) — семейства шрифтов, заголовки, основной текст, ссылки и кнопки, смысловое назначение начертаний.
- [Сетка, контейнеры и отступы](layout-grid.md) — Auto Layout, расстояния между блоками, схема вложенности, ширина контента.
- [Радиусы и обводки](radii-strokes.md) — таблица радиусов по типу блока, история пересмотра правила.
- [Иконки](icons.md) — набор Solid Icons, подбор по смыслу, реализация в коде.
- [Источники и работа с токенами](sources-tokens.md) — файлы Figma, принцип переноса в Variables/Text Styles, соглашение об именах токенов.
