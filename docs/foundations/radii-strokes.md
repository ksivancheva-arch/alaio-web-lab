# Радиусы и обводки

## Радиусы — по насыщенности содержимого, не единой ступенью

| Тип блока | Радиус | Примеры |
|---|---|---|
| Карточка секции (внешняя обёртка блока) | **30 px** | карточка «Top Menu Slider», «Chip», «Metaball» |
| Крупная тёмная карточка-секция | **40 px** | [Card Frame](../blocks/card-frame.md) — новая, более крупная ступень; пока встречена один раз |
| Крупный блок / превью (изображение, мокап продукта) | **20 px** | мокап `CRM` 880×430 в Top Menu Slider |
| Мелкий блок с текстом: заголовок + текст (± иконка) | **10 px** | панели в metaball-слайдере, карточки-преимущества в [Bullet Slider](../blocks/bullet-slider.md) |
| Мелкий блок только с иконкой + подписью, без отдельного текста | **8 px** | вкладки, chip, пункты бокового меню в metaball, кнопка раскрытия FAQ |
| Подложка иконки (36×36 и т.п.) | **8 px** | везде, где иконка — плашка, а не самостоятельный блок |
| Кнопка CTA (`Buttons / Primary / CTA` и `Secondary`) | **12 px** | CTA в хедере, CTA в блоках «Top Menu Slider» / «Chip», Secondary CTA в блоке «Partners» |

Значения, у которых нет строки в этой таблице (например, пункт FAQ — 20 px, контейнер FAQ — 0 px, пункт меню хедера — 46 px, см. [Header (Figma)](../blocks/header-figma.md)), — параметры конкретного компонента, не отклонение от таблицы; см. соответствующую страницу компонента/блока.

`radius/small` в Variables alaio-sites = 10 px — это верно для варианта «заголовок + текст»; вариант «только иконка + подпись» (8 px) пока не имеет своей переменной.

Радиус хедерной CTA (12 px, см. [Header (Figma)](../blocks/header-figma.md)) совпадает со ступенью «Кнопка CTA» из таблицы выше — вопрос закрыт.

Радиус подложки одиночной иконки — **8 px** везде, без исключений (решение от 15 сентября 2026) — совпадает со ступенью «иконка + подпись» из таблицы выше; см. [Основы → Иконки](icons.md).

## Обводки

Отдельного общего правила по толщине и цвету обводки в источниках нет. Толщина и цвет обводки определяются в спецификации каждого компонента/блока:

- Chip (карточка блока): 1 px, цвет по направлению — см. [Chips Block](../blocks/chips-block.md).
- Пункт FAQ (закрытое состояние): 1 px, `bg/lavender` — см. [Пункт FAQ](../components/faq-item.md).
- Кнопка Secondary: 2 px, `text/primary` — см. [Кнопки](../components/buttons.md).
- Кнопка раскрытия FAQ: 1 px закрыто / 2 px раскрыто — см. [Пункт FAQ](../components/faq-item.md).

## История пересмотра правила

Правило раньше формулировалось как «большие блоки — 20, мелкие — 10» без учёта содержимого; проверка на реальных блоках показала, что мелкие блоки делятся на два разных случая по объёму контента, а у карточек-секций и у CTA-кнопок — свои отдельные ступени (30 и 12), не входившие в старую формулировку. Таблица выше — актуальная версия правила.
