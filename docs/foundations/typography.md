# Типографика

## Семейства

- **Google Sans Flex:** крупные заголовки и кнопки.
- **Inter:** небольшие заголовки, основной текст и ссылки.

## Заголовки

| Стиль | Веб / Desktop | Мобильная версия |
|---|---|---|
| H1 | Google Sans Flex · 50 px | Google Sans Flex · 28 px |
| H2 | Google Sans Flex · 40 px | Google Sans Flex · 24 px |
| H3 | Google Sans Flex · 32 px | Inter · 20 px |
| H4 | Inter · 26 px | Inter · 18 px |
| H5 | Inter · 22 px | Не задан в источнике |

Каждый заданный заголовок имеет два начертания:

- Обычный: **Medium 500**.
- Accent: **Semibold 600**.

Для всех заголовков межстрочный интервал — **120%** (`line-height: 1.2`).

На мобильной версии H3 меняет семейство с Google Sans Flex на Inter. H5 Mobile не придумывать.

Пункт FAQ использует Inter Medium 500, 22 px, 120% — это стиль **H5** (обычное начертание); см. [Пункт FAQ](../components/faq-item.md).

## Основной текст

| Стиль | Веб / Desktop | Мобильная версия |
|---|---|---|
| Body | Inter · 18 px | Inter · 16 px |
| Body Small | Inter · 16 px | Inter · 14 px |
| Caption | Inter · 14 px | Inter · 12 px |

Каждый размер доступен в **Regular 400**, **Medium 500**, **Semibold 600**. Межстрочный интервал — **140%** (`line-height: 1.4`).

Подзаголовки (текст под H1–H5 в заголовочной группе) по умолчанию — **Regular 400**, а не Medium/Semibold. Кодовая реализация Hero — единственное известное отклонение (подзаголовок там Medium 500); это особенность конкретной реализации, а не пересмотр правила — см. [Hero](../blocks/hero.md).

## Смысловое назначение начертаний

Источник: [Untitled, Typography Guideline, node 32:1142](https://www.figma.com/design/Pp7s5FLAhwHha17DKRC9ZE/Untitled?node-id=32-1142) — эталонный лист типографики с колонкой «Usage» для каждого стиля. Размеры и line-height там совпадают с таблицами выше (расхождений не найдено); ниже — то, чего раньше не было в документации: явное назначение каждого начертания.

| Начертание | Назначение |
|---|---|
| Заголовок, обычный (Medium 500) | Основной вариант заголовка |
| Заголовок, Accent (Semibold 600) | Акцентная версия того же заголовка — только усиление, без отдельного смыслового статуса |
| Body / Body Small, Regular 400 | Основной текст, длинный контент |
| Caption, Regular 400 | Вспомогательная информация |
| Body / Body Small / Caption, Medium 500 | Вторичный акцент (secondary emphasis) |
| Body / Body Small / Caption, Semibold 600 | Сильный акцент (strong emphasis) |
| Link 1 | Основная (primary) ссылка |
| Link 2 | Компактная (compact) ссылка |
| Button | Подписи кнопок и первичные действия |

Это подтверждает уже принятое по ходу работы правило: **Regular — базовый текст, а не Medium** — Medium зарезервирован под вторичный акцент, а не является дефолтом для подзаголовков, подписей неактивных вкладок и т.п. Активная/неактивная вкладка меню следует той же логике на уровне начертания (Regular база → Semibold акцент), см. [Вкладки меню](../components/menu-tabs.md).

## Общие правила

- Межбуквенный интервал — стандартный, **0**, без дополнительного уплотнения.
- Сохранять отдельные стили Desktop и Mobile.
- Полный набор: **42 текстовых стиля** — 22 Desktop и 20 Mobile.
- Конкретный breakpoint переключения между версиями не согласован — см. [открытые вопросы](../design-system-open-questions.md).
- В Figma названия начертаний различаются: Google Sans Flex — `SemiBold`, Inter — `Semi Bold`.
